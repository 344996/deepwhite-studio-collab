# 全能数字人

先读取并遵守 `deepwhite-canvas` Skill 的“连接与定位”“写入画布”“执行生成”规则；工具出错时先调用 `studio_status`。

数字人效果取决于当前画布已配置的模型。开始前用 `list_models` 判断能力，并如实告诉用户能做到哪一步：

- 有支持参考图/首帧的视频模型：可以生成“形象图 → 说话视频”。
- 有音频（配音）模型：可以生成配音节点。
- 都没有：只完成口播稿与形象设定文字，并说明需要在“设置 → API”配置相应模型。

## 1. 立项

1. 提取：用途（口播/带货/讲解）、时长（默认 60 秒）、数字人形象（性别、年龄感、服装、场景）、语气、画幅（默认 9:16）。
2. `list_canvas_packages` 选择 `avatar-talk`，`import_canvas_package` 并填入 `主题`、`时长`、`形象`、`画幅` 变量。告诉用户画布地址。

## 2. 文字

用 `edit_canvas` 的 `update_prompt` 写入：

- 口播稿：按 150–180 字/分钟控制长度；开头 3 秒给出钩子；分成 3–6 段，每段一行。
- 形象设定：固定外观描述，后续所有形象图和视频提示词逐字复用。用户已导入真人照片时，只在用户明确确认拥有肖像授权后才作为参考素材使用。
- 分段画面：每段口播对应一个画面描述（景别、手势、背景、字幕要点）。

完成后请用户确认口播稿。

## 3. 生成节点

1. 用 `apply_nodes` 创建一个 `kind: image` 形象图节点（提示词 = 形象设定 + 场景，按画幅设置参数）。
2. 对每段口播创建一个 `kind: video` 节点，提示词写说话动作与表情；用 `edit_canvas` 把形象图连接到每个视频节点作为参考，把对应口播段文字连接到视频节点。
3. 模型支持音频时，为每段口播创建配音节点；不支持时在说明中写明需要外部配音。

## 4. 生成（需要用户授权）

用户明确同意后，先生成形象图，确认形象后再生成视频。遵守审批流程，用 `get_generation` 跟踪，最后汇总状态与实际费用。不得生成冒充真实他人的数字人，不得省略平台要求的 AI 生成标识。
