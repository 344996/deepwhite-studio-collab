深白片场 Windows 便携版 · 0.11.0-studio.5

一、打开画布
完整解压到自己的可写文件夹，再双击 Start.cmd。
无需安装 Python。不要在压缩包内运行，不要只复制启动文件。
本地编辑不用登录；生成图片、视频时再在“账户与 API”配置服务。

二、让 Codex 操作画布
1. 在同一台 Windows 电脑运行画布和 Codex。
2. 画布里打开“设置 → 外接智能体 / MCP”。
3. 勾选“启用 MCP 访问”，点击“自动配置 Codex”。
4. 点击“检查本机连接”，然后重启 Codex 的 MCP 连接或重新打开 Codex。
5. 点击“复制测试提示词”并发送给 Codex，确认能够列出画布。

程序自动使用你这台电脑的安装位置，不需要抄开发者的路径。
已有 Codex 配置会先备份，其他模型和工具设置保留。
“高级 / 其他客户端”中提供手动配置、撤回上次配置及诊断导出。
自动配置不安装 Codex，也不授权自动收费生成；默认每次生成需确认。

三、保留自己的项目
userdata 文件夹保存项目与设置；备份时先停止画布并复制完整 userdata。
自选的外部素材目录需另外备份。更新只切换程序版本，不覆盖 userdata。
移动安装位置时先停止画布，移动整个文件夹，从新位置打开后重新自动配置 Codex。
换电脑后也需在新电脑重新配置，不能照抄旧电脑路径。

四、遇到问题
连接失败先检查画布是否已打开、Codex 是否重启连接。
若检测到旧安装连接，确认要使用当前画布后更新配置。
启动日志在 updates/launcher.log 和 updates/server.log。
更多离线说明在 versions/当前版本/references/docs/客户安装与Codex连接.md。
请勿把密码、API Key 或完整 Codex 配置备份发给其他人。
