# 界面设计与维护指南 · 0.11.0-studio.3

日期：2026-10-20。适用于 `344996/deepwhite-studio-collab`，基于 0.11.0-studio.2。

> 按钮、图片与动画的后续细化已更新到 0.11.0-studio.4，见 [交互细节与动效维护](交互细节与动效维护.md)。本页保留 .3 布局设计与当时验证说明。

## 本次设计

参考 [LibTV 公开首页](https://www.liblib.tv/) 的左侧导航、清晰创作入口、快捷工具和作品优先的内容层级。没有把未访问的会员画布当作已验收依据，也没有复制其品牌、营销图片或收费入口。

深白采用深炭色背景、暖白主操作、淡薄荷色选中状态。侧栏负责定位，主区负责创作，画布尽量把空间留给节点。保留浅色、牛奶白和深色主题；原 `graphite` 设置值继续有效，显示名称改为“深色 · 薄荷”。

### 首页

- 增加欢迎区和有画面感的创作主入口，突出“新建画布”。
- 四个快捷入口说明各自用途；全部连接已有的创建、资产与设置操作。
- 项目卡片优先显示本地真实封面；没有封面时显示画布已有提示词的短摘要，仍为空则显示节点示意。
- 搜索、网格/列表、文件夹、新建、移动、回收站继续使用原生数据逻辑。
- 卡片菜单支持方向键、Home/End、Esc 和焦点恢复。移动导航支持焦点循环、关闭恢复及隐藏区域不可聚焦。
- 主入口插画使用仓库已有 AI 示例素材，并标注“AI 创作示意”；示意素材不写入用户项目，不代表用户的生成结果。

### 两种画布及生成记录

- 统一顶栏、添加工具、选择状态、底部整理工具、缩放条和按钮反馈。
- 节点媒体区域、提示词与参数编辑器统一边框、圆角、字号和间距；清楚显示键盘焦点。
- 修复窄屏整理工具与缩放条遮挡、旧宽度规则造成的溢出，以及智能画布素材按钮偏离工具栏的问题。
- 生成记录沿用 .2 的大图卡片、筛选、完整提示词、下载、放入画布和复用，统一本版配色和主次层级。
- 控件动效为约 120–220ms；首页一次淡入最长 600ms。遵守系统“减少动画”，不对节点坐标、画布平移或缩放添加缓动。

## 后续自己改哪里

| 要改的部分 | 文件及约束 |
| --- | --- |
| 颜色、主题、全局焦点、减少动画 | `app/static/studio-v2-theme.css`；改语义变量，不在各组件堆硬编码颜色 |
| 首页主入口、快捷入口、侧栏、移动导航 | `app/static/studio-workspace.js`、`studio-workspace.css`；创建按钮仍调用原生 `newCanvasBtn` |
| 项目卡片、封面摘要、搜索和菜单 | `app/static/studio-home-v2.js`、`studio-home-v2.css`；按项目/画布/更新时间隔离封面缓存，过期响应不能涂到新卡片 |
| 经典、智能画布的基础外观 | `studio-canvas-v2.css`、`studio-smart-v2.css` |
| 两种画布共用的最终工具布局 | `studio-canvas-workspace.css`；先检查最终计算样式，避免旧定位、宽度规则再次生效 |
| 节点媒体和输入编辑区 | `studio-node-composer.css`；不要改变世界坐标或缩放逆变换 |
| 生成记录卡片 | `studio-generation-history.css`；行为在 `studio-history-view.js`，保留懒加载、预览失败与复制失败处理 |
| 设置主按钮与主题名称 | `studio-settings-v2.css`、`studio-settings-v2.js`、`studio-milk-theme.js` |

主要变量：

```css
--dw-bg: #141616;          /* 页面 */
--dw-canvas: #101212;      /* 画布 */
--dw-surface: #1c1f1f;     /* 卡片与浮层 */
--dw-primary: #f1f3ec;     /* 主按钮 */
--dw-on-primary: #191e1b;  /* 主按钮文字 */
--dw-accent: #b9e7cf;      /* 选中与焦点 */
--dw-ink: #f2f3ef;         /* 主要文字 */
--dw-muted: #b5bdb9;       /* 次要文字 */
```

`--dw-gold*` 是历史兼容名称，现在引用 `--dw-accent*`，不必一次性重写全部旧工具。浅色主题在同一文件覆盖变量。文字用 `textContent` 写入，不能把用户标题、提示词、错误或 API 返回内容直接拼成 HTML。

视觉层的加载顺序是旧界面 → V2 → workspace / canvas-workspace / node-composer 等专项增强。修改前先找最终生效规则；例如旧 `position:fixed` 对应的 `right` 值，在切换为 `position:relative` 后仍可能造成偏移。新增尺寸必须在 320、768、1024、1440px 验证，短窗口也要能访问所有工具。

## 复查方式

设置本机的 `PLAYWRIGHT_MODULE`、`CHROMIUM_EXECUTABLE`、`PYTHON_EXECUTABLE` 后，使用 Node 运行：

```text
node app/tests/check-workspace-polish.cjs
node app/tests/check-canvas-chrome-polish.cjs
node app/tests/check-history-refinement.cjs
node app/tests/check-feedback-1020-ui.cjs
node app/tests/check-home-v2.cjs
node app/tests/check-mj-history-0929.cjs
```

使用临时服务和合成项目，浏览器/测试服务拦截外部和付费生成。前两项专门检查布局、真实点击命中、文字裁切、主题、减少动画和键盘链路；其余验证原生创建、重命名、移动、回收站、保存重载、撤销重做、连线及记录复用。

测试截图位于本机 `app/test-output/workspace-polish/`、`app/test-output/ui-polish/canvas/`、`app/test-output/history-refinement/`，不作为用户作品提交到源码仓库。测试结果汇总见 [本轮验证记录](verification-ui-polish-20261020.json)。

## 兼容和交付边界

- 本轮更新源码和本机预览；没有重新打包 Windows ZIP、发布 GitHub Release 或改变公共更新源。
- 无后端协议、画布 schema、账号、API Key 或作品目录迁移。不清理旧项目、记录或素材。
- 画廊维持 0.4.0 / schema 4；本轮美化对象为画布工作台，未重新设计独立画廊网站。
- 未进行真实收费生成、客户另一台电脑验证、触屏设备及长期大画布性能验收。
- 重启本机预览前单独备份其数据目录并核对文件哈希；备份不覆盖用户自行配置的外部素材目录，完整迁移仍应另行备份这些目录。
- 回到旧代码前先停止服务并备份最新数据；本版没有 schema 迁移，但不能据此推断任意更老版本均兼容。

其余能力和未完成项见 [本版完整累计状态](../app/docs/releases/0.11.0-studio.3-status.md)。
