# 按钮、图片与动效维护 · 0.11.0-studio.4

日期：2026-10-20。仓库：`344996/deepwhite-studio-collab`，基于 0.11.0-studio.3。

## 这一版改了什么

沿用上一版深炭、暖白和薄荷色，参考 [LibTV 公开首页](https://www.liblib.tv/) 的克制反馈：鼠标悬停轻微提亮，按下短促收紧，松开平滑恢复。此次没有重排首页，也没有改动账号、生成服务、MCP 或保存协议。

| 操作位置 | 反馈与行为 |
| --- | --- |
| 首页、画布工具栏、设置按钮 | 悬停浅色叠层；按下约 2.5% 收紧；选中项、主操作和危险操作保留自身颜色 |
| 首页快捷入口 | 图标轻微变亮、尾部箭头前移；取消上一版整个入口上浮，避免按下时叠加跳动 |
| 真实项目封面 | 图片轻微放大和提亮；按下回落。点卡片内菜单时，只反馈菜单按钮 |
| 生成记录图片 | 整张图片是放大预览入口，右下保留文字提示；支持鼠标、Enter 和空格 |
| 项目资产缩略图 | 改为带可访问名称的原生按钮，支持点击和键盘打开预览 |
| 视频和音频 | 保留播放器自身控件；不使用图片按钮遮住播放、拖动进度或音量操作 |
| 加载、禁用、取消 | 按下后移出、滚动、触摸取消、窗口失焦会释放状态；异步进入 busy/disabled 时同步撤销反馈 |
| 减少动画 | 关闭缩放、位移、动画与过渡；保留即时颜色和键盘焦点反馈 |

一并修复经典、智能画布把按钮上的空格键误作平移的问题。焦点在控件时保留原生激活；焦点在画布背景时空格平移继续有效。

| 画布快捷键与原生控件兼容 | `app/static/studio-canvas-v2.js`、`studio-smart-v2.js`、`js/smart-canvas.js` |
| 专项浏览器测试 | `app/tests/check-interaction-details.cjs` |

交互脚本接入六个现有页面：工作台、经典画布、智能画布、设置、原 API 设置和项目资产。脚本跟随自身 `?v=` 加载 CSS；HTML 版本由现有启动机制更新，避免新版脚本仍读取旧交互 CSS。

可以优先调整这些变量：

```css
--dw-feedback-in: 140ms;       /* 悬停颜色 */
--dw-feedback-down: 70ms;      /* 按下 */
--dw-feedback-out: 200ms;      /* 松开回弹 */
--dw-feedback-tint: #ffffff07;
--dw-feedback-pressed: #ffffff0d;
--dw-feedback-brightness: 1.06;
```

浅色主题使用淡绿色叠层和 `brightness(.985)`；不要直接给所有主题套白色提亮。图片放大目前为 `scale: 1.025`，项目卡片按下为 `.993`，按钮按下为 `.975`。不要增加夸张弹跳、循环闪动或全屏光效。

## 扩展约束

- 新功能优先用原生 `<button type="button">`、`<a href>`、`<summary>`。不要仅加 `cursor:pointer` 就把普通图片伪装成按钮。
- `data-dw-hover` / `data-dw-press` 只记录短暂视觉状态，不写入项目、生成记录或 localStorage。脚本不合成点击、不阻止默认事件，也不接管生成和保存。
- `aria-disabled` 表达状态，不会自行阻止原生点击。实际禁用动作仍由组件使用 `disabled` 或自己的动作检查负责。
- 动态状态观察只连接当前悬停、按压控件及其祖先，离开后断开；不要把所有节点更新纳入全树观察。
- 图片预览只覆盖图片区域。图片加载失败时隐藏全图按钮，让重试可操作；视频、音频继续使用原生控件。
- 装饰插画、静态记录卡片、节点拖动区不能因为美化变成新动作。需要排除某个交互子树时使用 `data-dw-feedback="none"`。
- 不给 `.node`、`#world`、画布位置或缩放加缓动。不改节点坐标、连线命中、撤销栈和画布保存数据。
- 新增按钮应同时检查鼠标、Tab、Enter/空格、disabled/loading、触屏取消及 `prefers-reduced-motion`。

## 交付、备份与恢复

本版交付源码和本机预览，不重新打包 Windows ZIP、不发布 GitHub Release、不改变公共更新源。此前 0.11.0-studio.1 本地便携包仍是旧版。

画廊仍为 0.4.0 / schema 4，本轮未改独立画廊界面。原有真实账号/付费模型、客户异机、长期大画布性能等验证边界继续保留。完整状态见 [本版累计状态](../app/docs/releases/0.11.0-studio.4-status.md)。
