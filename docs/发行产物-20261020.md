## 实际 ZIP 的 8 项验收

`scripts/check_current_release.py` 在一个全新、含中文、空格和 `&` 的目录中解压实际产物，执行以下检查，全部通过：

1. 三个产物的文件大小和 SHA-256 一致。
2. ZIP 完整，包含离线文档、Skill、运行时，不带用户数据、日志或私钥。
3. 从 PATH 移除系统 Python 后，实际 `Start.cmd` 启动成功，健康版本为 0.11.0-studio.1。
4. 创建、保存和重新读取含中文的文字节点一致。
5. 首页、设置、两类画布可读取；旧内置助手路由为 404，聊天页无 Agent 请求分支。
6. 设置页生成的固定 MCP 入口对实际安装预检成功。
7. 固定入口完成真实 stdio 初始化、发现 13 工具和项目读取。
