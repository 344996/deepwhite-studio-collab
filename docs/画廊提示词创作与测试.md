# 画廊提示词创作与测试

更新：2026-10-19。画布 **0.10.2-studio.15**，独立画廊 **0.2.0**。

用户允许自主完成基础架构，并接受“在画廊直接生成，或者跳回画布/API 网站”的方式。本轮实现跳转与提示词导入；站内直接生成没有冒充已经接通，微信继续暂缓。

## 使用方式

1. 在画廊发布提示词、图片或 MP4。图片/视频的提示词由作者主动选择公开；纯提示词作品必须有正文。
2. 审核公开后，访客在详情点“使用此提示词创作”。可以复制、导出 JSON、带到本地画布，也可以前往 API 网站。
3. 先启动本地画布，打开导入页预览，选择项目并确认创建；画布里会有一个文字节点。
4. 使用现有画布连接图片/视频生成节点，选择自己的 API 和模型后生成。当前不会自动执行模型，也不会自动搬运参考图片、视频、密钥或模型参数。
5. 无法打开本机链接时保留导出文件，从本地“公共画廊 → 导入提示词文件”继续。网站按钮只打开 API 站首页，不自动填词。

## 自己继续改

完整逐文件说明在画廊仓库：[画廊基础架构与修改指南](https://github.com/344996/deepwhite-gallery/blob/main/docs/画廊基础架构与修改指南.md)。它包含配置表、文件入口、数据和接口契约、配额、备份回退、以及以后接站内生成的步骤。

本地相关文件：`app/studio_gallery_import.py`（校验/原子创建/收据）、`app/static/studio-gallery-import.html/.css/.js`（预览与文件导入）、`app/static/studio-workspace.js`（入口）。公共网站通过自己的 `gallery/creation.py` 与 `static/creation.js` 导出数据；不会远程控制本机。
