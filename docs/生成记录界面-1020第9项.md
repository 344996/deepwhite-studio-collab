# 1020 第 9 项：生成记录界面

对应版本：**0.11.0-studio.2**，2026-10-20。

## 需求理解

用户文档原文是“生成记录界面太难看”，附图为旧的纵向记录弹窗：图片很小，提示词、参数、失败信息和按钮挤在同一个长框中。文档没有规定具体颜色、卡片尺寸或新的收费逻辑。

本次将其落实为以下界面与操作改进。它们是针对附图的实现方案，不冒充文档逐字要求：

| 附图中的问题 | 本次处理 |
| --- | --- |
| 图片太小，记录像日志文本 | 结果在卡片上方大图展示，原比例显示；支持图片放大、视频与音频控件、文本摘要 |
| 信息层级混乱 | 状态徽标、模型、提示词、时间和实际费用分层；完整提示词和原始参数折叠收纳 |
| 下载、复用、放入画布混在正文中 | 操作统一到卡片底部，“放入画布”突出显示；多结果保留各自下载和放入入口 |
| 成功、失败和进行中不易区分 | 图标和文字共同标识状态；失败原因用可读文字显示，保留原错误信息 |
| 记录多了难找 | 图片/视频/音频/文本快速分类，叠加关键词、任务编号、状态与时间筛选，并提供重置 |
| 小屏容易挤压和截断 | 3/2/1 列响应布局；筛选区自然换行，列表独立滚动，操作不被底部遮挡 |
| 异常时只出现空白或原始错误 | 加载、空记录、无匹配、读取失败重试、媒体加载失败重试分别处理 |
| 两种画布的记录体验不一致 | 经典和智能画布共用呈现模块；保持各自保存和节点操作实现 |

保留了明确的“复制提示词”和“复制原始错误”入口，提示复制成功或失败。本地图片走缩略图，首个结果进入可见范围才加载；其余结果在展开详情后读取，避免一次加载全部原图。

额外处理了与此界面直接相关的两个交互问题：关闭弹窗时暂停正在播放的媒体；关闭后再打开时，旧的异步响应不能覆盖新一轮记录。加载期间仍可输入筛选条件。

## 使用

进入画布，点击“生成记录”。点击类型按钮或输入关键词查找记录；“提示词与参数详情”可展开全文和其他结果。“复用这次设置”创建带原参数的经典画布节点，“复用提示词”在智能画布创建文字节点，均不自动发起生成。

“放入画布”沿用原生节点与保存逻辑。没有平台实际账单时仍显示费用未知。MJ 的查询、保存恢复和结果待核实限制继续保留，不把重试保存改成重新生成。
