# 手动测试反馈回复

## 一、API 登录后不能自动配置（已修复，真实网站验证通过）

**原因**：官方网站的令牌规则和标准 New API 不同。完整密钥只在创建令牌时返回一次，之后再取会返回 HTTP 410，只能重新生成。旧代码创建时没有保存这个密钥，接着去取，于是令牌建好了，配置却失败，错误又被盖成“请检查输入后重试”。

另外，注册成功后不会自动登录，要重新输入账号和密码。

**修复**：
- 创建令牌时直接使用返回的密钥；
- 已有令牌取不回密钥时自动重新生成，不会多建令牌；
- 注册成功后自动登录并配置；自动登录失败时回到登录表单，保留用户名并说明原因；
- 网站拒绝时显示网站给的原因。

**影响**：每次重新登录都会重新生成这个本机专用令牌的密钥，旧密钥作废。密钥不写入硬盘。

**真实网站验证**（测试账号 `test1`）：

| 项目 | 结果 |
|---|---|
| 注册、邮箱验证码、注册后自动登录 | 成功 |
| 官方 API 自动配置 | 成功，未填写 API Key |
| 模型同步 | 236 个 |
| 生成一张图片（Image G V2.5 Lowprice，1 张，1:1，1K） | 成功，约 4 分 22 秒，已存到本地 |
| 费用 | 预估 ¥0.051，实际 ¥0.051；余额 ¥20.00 → ¥19.949 |

**尚未真实验证**：其他图片模型、视频、音频、文本和 RunningHub 工作流的调用。

## 二、节点详细信息点击才显示（已修改）

之前只折叠已出结果的节点。现在图片、视频、文本、音频节点无论是否生成过，没选中时都只显示结果和名字。
