## Windows 包、本机启动与历史

本版通过已提交源码构建；版本 ZIP、完整便携 ZIP、签名清单、SHA-256 和构建来源记录一并生成。解压包验证脚本为 `scripts/check_current_release.py`，使用独立目录和自带 Python 检查启动、保存重读、助手移除、稳定 MCP 入口及重启数据保留。

源码运行和便携包分开。本机预览由 `deepwhite-development-20261019/local-preview/Start.cmd` 管理，画布 `http://127.0.0.1:3849/`、演示画廊 `http://127.0.0.1:3857/`。同目录 `Stop.cmd` 只停止已记录且身份匹配的进程。启动前已停写备份：画布目录复制，画廊 schema 3 备份经 SHA-256 和数据库结构校验；备份保存在本机，不进入公开仓库。

演示画廊使用明确标注的固定身份 `demo_admin / demo` 和 `demo_author / demo`。它们不是 API 网站账号；管理员可体验发布、审核和反馈处理，没有给真实用户提权。画布仍可免登录编辑，真实 API 站登录入口保留。

**本轮不发布新的公共 GitHub Release 或替换在线更新源。** 本地 ZIP 可用于验收；GitHub 源码提交、便携构建和公开更新是三个不同状态。上一公开版发行证据保留在 [20261019 发行记录](发行产物-20261019.md)。

## 需要继续确认的边界

- MCP 是本机工具协议，`127.0.0.1` 属于启动桥接的电脑。不同电脑、WSL 或远程容器不能直接照抄另一台电脑的路径。本次没有远程访问反馈中那台电脑，无法声称其实际故障已现场修复。
- 自动授权依据 New API 官方接口，真实网站若关闭令牌管理或修改契约，会显示“自动连接未完成”。当前没有用真实账户创建令牌或调用收费模型。
- Claude 的配置格式有测试，但没有安装真实 Claude 客户端联调。外接 MCP 仍只覆盖已定义的普通画布操作。
- 画廊公网、站内直接付费生成、多媒体合集、完整运营系统、未来数据 schema 迁移和长期性能仍按累计清单保留，微信继续暂缓。
- 画廊 schema 4 回退须使用匹配的旧快照；先另存最新数据。反馈截图和正文属于私人数据，不能随源码或安装包分发。
