# 公共画廊接入与测试

日期：2026-10-18。画布版本 **0.10.2-studio.13**，独立网站版本 **0.1.0**。

用户选择“网站公共画廊：用户登录后发布和分享作品”，指定 API 站 `https://api.deepwhiteai.com`，授权新建后端仓库。域名尚未确定，微信接口明确暂缓。

## 本次完成

- 本地画布主页与两种画布均增加“公共画廊”入口，网址可保存、清除并在新标签页打开。网址原子保存，保存失败保留原配置；拒绝不安全远程 HTTP、URL 凭据和查询参数。
- 独立 [画廊仓库](https://github.com/344996/deepwhite-gallery) 提供网站前端和后端：账号站登录/2FA、注册与找回入口、主动上传图片/MP4、草稿、标题/说明/标签、可选提示词、审核/退回/下架、公开搜索/浏览/分享、作者撤回/删除。
- 本地画布继续免登录编辑，用户仍可选择自己的生成服务。只有用户在网站主动选择的文件会上传，不自动同步画布或 API Key。
- 画廊单独存储数据库和媒体；账号密码不落盘，生成 Key 不参与认证。权限、CSRF、文件体积、类型、配额、重复请求与版本冲突都有检查。匿名会话、透明 PNG、Windows 文件占用删除和任务取消清理均补了回归。
- 配套部署配置、备份说明、API/AI 开发指南和验收记录。网站仓库暂建为私有，画布仓库继续公开。

## 使用与剩余事项

1. 按独立画廊 README 在本机启动网站，默认地址 `http://127.0.0.1:3856`。
2. 在画布“公共画廊”中保存此地址，然后点击“打开画廊”。正式网站上线后再改为 HTTPS 域名。
3. 上线前补画廊域名、部署主机和真实审核员数字 ID，完成真实账号联调与上线验收。
