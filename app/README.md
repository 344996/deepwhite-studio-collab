## 打开方式

从仓库根目录双击 `启动深白片场.cmd`，由该入口启动 `app/` 副本。上一版记录的地址 `http://127.0.0.1:3848/` 与 health `0.10.1-0929.1` 是历史运行核验；本轮不重启真实服务，补丁运行核验待下次启动。端口在 3848–3858 范围内自动选择，以实际启动输出和 health 为准。

旧版单独启动入口、路由和功能说明保留为 0.9.0-feedback.1 的历史记录，使用前核对当前工作区启动输出和[本版状态](docs/releases/0.10.2-studio.10-status.md)。

- 工作台 `/`：保留原项目管理、画布列表、回收站和原画布功能。
- 交互稿 `/preview`：试用四类节点菜单、模型选择、参数面板、参考图切换和价格显示。不会提交生成、不会保存画布。
- 原功能入口 `/original-tools`：保留原程序的完整功能导航，后续按已确认范围整理可见入口。
- 停止：双击 `停止深白片场.cmd`，旧停止入口保留。
- 本地智能体：进入「设置 / API → 本地智能体（MCP）」启用并复制客户端连接配置。默认生成逐次确认，也可主动开启限时授权。

## 已确认需求

1. 新目录、新启动入口、新数据，来源是原始无限画布，不是前一版 DeepWhite-Canvas。
2. 原画布基础功能全部保留。新增/替换节点操作区时继续使用原引擎的选择、拖动、缩放、连线、分组、复制、删除、撤销、保存、素材管理等行为。
3. 双击空白处添加节点：文本、图片、视频、音频；菜单底部保留上传、从作品导入。其他扩展节点先隐藏；2026-09-17 追加独立「MJ 工具」入口。
4. 四类节点都要通过 DeepWhite API 生成；音频不是仅支持上传的素材节点。
5. 一个类型一个节点，在节点里选择模型和参数。参考图有无自动决定文生图/图生图调用，不擅自更换用户选定的模型系列。
6. 视频首帧、尾帧、多参考素材按模型能力处理，不能只根据文件数量猜测用途。
7. 参数联动费用估算；使用 DeepWhite 自己的价格。预估与最终实扣分开，无可靠报价不显示零元。
8. 对照 DeepWhite API 文档与 T8 调用代码逐模型核对。模拟测试先行，尚未获准消耗生成额度。
9. 统一 DeepWhite 品牌。后续再增加工作流及短剧工具集成。

## 两级模型、估价与 MJ 工具（2026-09-17）

- 模型按「系列 → 具体版本」显示；文生图列表排除 MJ 后处理、图像编辑/分层/放大等操作，兼容文生图与参考图的同系列模型仍自动分流。
- 普通画布节点、智能画布操作区读取本站公开费用资料，缓存 5 分钟；匹配历史参数，按次数估算，视频不重复乘时长。没有可靠记录不显示零元；文本显示按实际 Token 用量计费。
- 独立 MJ 工具按各操作动态展示输入。文生图位于图片节点，其余 15 项操作在 MJ 工具中；采用 `/v1/midjourney/generations/{action}`，查询采用 `/v1/midjourney/tasks/{id}`，不复用 APIMart 路由。
- MJ 识图返回文本，视频返回视频；局部重绘处理 MODAL 状态并进入遮罩提交步骤。任务编号随画布保存，刷新后可只查询，不重新提交。
- 新模块：`studio_pricing.py`、`studio_midjourney.py`、`static/studio-tools.js/.css`。运行时 `studio_mj_tasks.json` 保存任务与平台地址绑定，不存密钥。
- 实际生成只做模拟验收，没有消耗 API 额度；上游真实端到端生成仍待用户另行授权。

### 节点内直接输入（2026-09-17）

图片与视频节点均可直接填写提示词，连接文本作为补充。`static/studio-node-editor.js/.css` 提供输入保存、内容自动展开和较大默认尺寸。Seedance 默认全能参考，生成与估价使用同一模式；用户可以改选首尾帧。
