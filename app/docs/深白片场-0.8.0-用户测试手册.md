# 深白片场 · 用户测试操作手册

适用版本：**0.8.0-mcp.1**　编写日期：2026-09-25

这是一份按顺序操作的验收清单。程序已有模拟测试，但真实平台、真实模型、真实扣费和你本机的运行效果，需要在这里逐项确认。每项填写：通过 / 失败 / 阻塞 / 未测。没有账号、模型或运行环境时记为“阻塞”，不要记为通过。

## 1. 开始前

1. 双击项目目录内的 **启动深白片场.cmd**，进入启动器打开的主页。默认地址为 `http://127.0.0.1:3848/`，以实际启动地址为准。
2. 在正式首页新建项目 **验收测试-0925**，新建一个**普通画布**“基础测试”。不要在 `/preview` 设计预览中测试保存或真实生成。
3. 准备一张人物图、一张场景图、两张不同图片、一段可正常播放的短视频。全部使用测试副本。
4. 先完成第 2～4 节，再进行付费测试。第一次每个模型只生成一张图片或一段短视频。
5. 测试时记下当前版本、模型名称、通道、参数和任务编号。反馈截图请遮住密钥和登录凭证。

**费用标记：**【不生成】不提交生图/视频任务；【可能计费】会调用对话模型、图片/视频服务，或消耗第三方积分；【本机】使用本地 ComfyUI 和显卡。

> 内置“画布助手”和外部“MCP 智能体”是两个入口。内置助手对话本身可能计费，确认方案只写入节点；外部智能体通过 MCP 可以申请真正生成，需要单独授权。

## 3. API、模型和账户【不生成】

| B04 参数和估价 | 选一个有价格数据的型号，改变张数、分辨率或视频时长，稍等报价返回 | 有依据时显示估价；参数变更后更新。未知价格应明确标示，不能显示假零元 |

入口：画布“资产库”；保存位置也可在“设置 / API → 基础设置 → 本地项目存储”找到。

| 编号 | 操作步骤 | 预期结果 |
|---|---|---|
| C01 导入与归档 | 导入测试图片和视频；搜索名称、预览；将一项候选确认为正式资产，再测试归档 | 状态、搜索、预览正确；重新打开资产库仍存在 |
| C02 引用与删除 | 将正式资产引用到画布；只删除画布上的测试节点，再查看资产库 | 资产及其本地文件仍保留，节点删除不等于资产删除 |
| C03 设置目录 | 在本地项目存储中选中“验收测试-0925”，选择一个专用空目录，点“保存 / 迁移到此目录” | 当前项目路径更新，点击“打开当前目录”可查看。路径示例：`D:\深白片场测试\项目A`，以本机可写磁盘为准 |
| C04 迁移校验 | 有少量素材后，将同一测试项目迁到另一个空目录；等待完成再重开画布 | 新位置有文件；图片/视频引用不失效；原目录文件保留 |

| C06 生成落盘 | 完成后面的真实生成后，回到当前目录检查新文件，重开软件再预览 | 不只是网页临时显示；本地文件存在且重开可读取 |

目录迁移时等待所有生成任务结束。**媒体目录不是完整项目备份**：画布、提示词、参数、资产索引和会话还在软件工作区。完整备份需同时保留工作区及外部项目素材目录。本版没有任意文件夹双向同步。

## 5. 图片、视频与专业处理

### D01 文生图【可能计费】

1. 创建图片节点，不连接参考图；选择已适配的图片模型，张数设为 1。
2. 输入：`一只橘猫坐在木桌上，窗边自然光，背景简洁，写实摄影，主体完整清晰。`
3. 查看估价，点击生成一次，等待结果。记录任务编号和平台实际扣款。
4. 检查结果能预览、保存、作为下一个节点的素材；刷新后仍存在。

**预期：**生成期间节点不来回跳动，状态清楚；成功显示真实图片；失败展示具体原因，不只有“400”。提交不确定时先查日志/平台任务，不要连续点击重试。

### D02 图片编辑与多图【可能计费】

1. 将人物图连接到兼容编辑的图片节点，确认缩略图出现。
2. 输入：`保留人物的脸部特征和发型，将外套改为深蓝色，其他内容尽量保持一致。`，生成一张。
3. 对支持多张输出的模型，另测一次 2 张；在结果节点查看，再进入大图左右切换。

**预期：**编辑确实使用参考图；多张结果集中显示，浏览顺序正确。记录模型是否真正保留人物，而不只记录“接口成功”。

### D03 标准人设图【可能计费】

1. 点击上传的人物图，在处理功能中选择“标准人设图”。再对生成的人物图检查同一入口。
2. 查看案例图、默认推荐 GPT 型号，并尝试改选另一兼容型号。
3. 选定型号生成一次，不需要重新填写模板提示词。

**预期：**默认模板原文不占界面；有案例；原图保留；结果为灰底人物三联设定图。核对侧向头像、正面全身、背面全身及人物一致性，构图以产品案例和既定模板为准。

### D04 其他图片处理【生成操作可能计费】

- 对人物图分别打开换服装、装备、手持物等已有处理入口，先检查素材和参数，再挑一项生成。
- 对场景图测试改视角或反向镜头，检查主要空间和物体是否对应。
- 测试涂改/标注：标出修改处、写明要求，提交兼容编辑模型。原图应保留。当前是标注参考引导，不是保证区域外完全不变的原生蒙版编辑。
- 建立独立双图对比节点，放入两张图，拖动滑块；刷新后再次检查。它应是一个对比节点，不是两张独立图替代对比功能。

### D05 Seedance 视频【可能计费】

1. 新建视频节点，选择支持全能参考的 Seedance 版本，检查默认参考模式。
2. 连接人物图和场景图，确认两张缩略图；在提示词中输入 `@`，从实际素材菜单插入引用。
3. 填写：“[人物引用] 中的人物站在 [场景引用] 的窗边，缓慢转头看向镜头，镜头轻轻推进，保持人物和环境一致。”方括号处替换成菜单插入的实际引用，不能照抄成普通文字。
4. 调整一次素材顺序，检查引用仍对应原素材；选择模型允许的短时长，提交一次。
5. 查看状态、结果播放和本地视频文件。

**预期：**引用不是单纯显示几个 @ 字符，而是正确关联素材；视频可播放、有合理时长；平台任务和本地结果对应。首尾帧模式只在支持它的型号上单独测试，不把全能参考与首尾帧混用。

### D06 关键帧【不生成】

上传可播放的视频，通过其处理入口打开关键帧截取；定位两个不同时间点，分别截取。检查两张帧图能显示、引用和保存，画面与时间点对应。本版是手动截帧，不是自动分析镜头。

### D07 Midjourney【可能计费】

先以 1 次 Imagine 测试提示词、参考图、参数、估价和结果；再在已有结果上测试界面支持的一项后续动作。记录动作名称与源任务编号。重点检查生成期间界面不跳动，后续动作使用正确结果；本版并非完整 MJ 风格库。

## 6. 本地 ComfyUI 与即梦（可选）

### E01 ComfyUI【本机】

1. 在右上状态/设置入口核对整合包路径；如果已有外部启动的 ComfyUI，先检查能否识别，避免重复启动。
2. 根据需要点击开启，观察启动中 → 运行中的状态；失败时查看启动日志。
3. 图片节点选择“本地 ComfyUI → Qwen 单图编辑”，连接一张参考图，填写简单修改要求，生成一次。
4. 查看输出与本地文件；修改采样步数或提示词优化开关，再核对实际执行记录。

**预期：**可不打开 ComfyUI 工作流页面完成调用；不扣 API 额度。只有已适配工作流可用，不能因此认定任意本地模型都支持。关闭引擎测试应在没有任务时做；外部启动的服务可能不允许在画布内直接关闭。

### E02 即梦【可能消耗平台积分】

1. 在设置中的即梦通道启用并完成本机 CLI 授权；若缺少 CLI 或无法授权，记录“环境阻塞”。本版没有一键安装器。
2. 查看可用模型，停用再启用一个型号，核对画布菜单更新。
3. 选择即梦通道，先生成 1 张图；有需求再测试短视频。
4. 检查平台任务状态、积分变化、画布结果和本地文件。

**预期：**用户能分辨这是即梦账号通道，不是 DeepWhite API 扣款；关闭通道后不能继续新提交。本版没有小云雀账号通道，暂不验收。

## 7. 内置画布助手与 Skill【对话可能计费】

入口：普通画布右上 **画布助手**。选择对话模型、图片目标和视频目标。多选技能或资产时可按住 Ctrl 选择。

### F01 剧本分析 → 节点方案

将下面内容保存成 TXT，点击“添加 TXT / MD / DOCX”上传，选择资产拆解类技能：

> 傍晚，旧书店内。年轻女店员林夏穿着灰色针织衫整理书架。快递员陈默穿深蓝夹克推门进来，将一个牛皮纸包裹放在木柜台上。林夏看到包裹上的红色蜡封，停下手中的动作。

发送：

> 分析附件中需要的人物、场景、道具资产，合并重复项。为每项编写可独立生成的提示词，并提出对应图片节点方案。先让我检查，不要生成图片。

**检查：**主要人物、书店、关键包裹没有遗漏；提示词可编辑；显示节点方案，但确认前没有写入画布。

### F02 多轮修改 → 写入 → 撤销

接着发送：

> 林夏改为黑色短发，陈默穿灰色夹克。不要新增剧情，更新刚才的方案。

检查修改是否继承其他设定；确认方案写入后，核对节点标题、提示词和模型。测试整批撤销，确认撤销范围正确。内置助手此处不应自动开始生图。

### F03 资产 → 视频提示词与映射

先在资产库准备人物图和场景图；在助手中选择这些项目资产，选择视频提示词技能，发送：

> 使用我选择的人物和书店资产，为“陈默把包裹放到柜台，林夏看向红色蜡封”创建一个视频节点方案。写出动作与镜头提示词，关联正确素材并建立 @ 映射。先不生成视频。

确认后逐项检查节点、提示词、素材缩略图、连线、@ 指向。**提示词写得好不好、人物是否串图，也是验收内容。**

### F04 自己的 Skill

点击“导入技能文件夹”，选择含 `SKILL.md` 的测试技能目录；在“调用技能”中选择它，发起符合技能职责的任务。检查助手是否遵循你的规则。当前仅支持文本技能及引用，不执行技能脚本。刷新后检查历史会话可重新打开。

## 8. 外部本地智能体 MCP（本版新增）

### G01 连接【不提交媒体生成；外部智能体对话可能计费】

1. 保持深白片场运行，打开“设置 / API → 本地智能体（MCP）”。
2. 开启访问，保持“逐次确认”，复制客户端配置。
3. 在支持 **stdio MCP** 的智能体客户端中添加配置，并按该客户端方式重新加载连接。不同客户端入口不同，配置片段不能当成聊天消息发送。
4. 要求智能体“列出深白片场中的普通画布及可用模型，不修改、不生成”。

**预期：**能读到当前项目；如果客户端不支持此配置格式，记为接入阻塞并提供客户端名称/版本，不反复重装整个项目。无需把平台 API 密钥贴给智能体。服务端口改变后重新复制配置。

### G02 创建、关联与修改【不生成】

给外部智能体发送：

> 读取“验收测试-0925”项目中的“基础测试”普通画布，读取可用模型和资产。创建一个人物图片节点和一个视频节点，填写测试提示词；视频节点使用项目里现有的人物与场景资产，连接素材并建立正确引用。只编辑画布，不申请生成。记录本次操作编号。

**预期：**打开的画布自动出现节点、文字、素材和连线。再要求修改其中一个节点，不应无故重复新增。要求撤销刚才的编辑，检查只撤销本次操作；画布已有后续变化时拒绝不安全的旧撤销属于正常保护。

### G03 逐次确认与拒绝

让智能体为一个测试图片节点申请生成，先不批准。打开 MCP 设置查看待确认列表。

- 核对提示词、模型、张数及参考素材，再点“拒绝”：不应产生生成任务。
- 再明确申请一次新的生成；确认内容无误后“批准”：**这一项可能计费**，应创建任务并把结果回写画布。
- 要求“查询刚才任务结果，不重新提交”：不应新增第二个任务或再次扣款。

批准前改动节点提示词再批准旧请求，应提示内容变化并要求重新申请，而不是按旧内容悄悄生成。

### G04 临时授权与关闭

开启“本次授权”，检查剩余次数和到期说明，再立即结束授权；不需要为了测试而消耗 20 次生成。结束后新生成请求应再次要求确认。关闭 MCP 访问后，外部智能体不能继续控制画布。

**注意：**最长 30 分钟、最多 20 次是请求授权，不是金额预算，一次请求可含多张图。

### G05 多窗口冲突（进阶，可跳过）

## 10. 怎么把问题反馈给我

一个问题单独记录，不要只写“不能用”。复制下面模板即可：

```text
测试编号：例如 D05
版本：0.8.0-mcp.1
结果：失败 / 阻塞
项目 / 画布：
使用的通道与模型：
操作步骤：1.… 2.… 3.…
预期结果：
实际结果及完整错误文字：
是否每次出现：
发生时间 / 任务编号：
是否在平台产生任务、是否扣费：
截图或短录屏：
```

生成异常请同时保留节点状态和“日志”中的相关记录；不要发送完整密钥。遇到**内容丢失、重复扣费、错误覆盖文件**，停止该项重试并保留现场。画质不满意和程序报错分开记录，前者需要同时附上输入素材、提示词和结果图。
