# MJ 翻阅与生成记录修复

- 普通画布的 MJ 多图结果节点新增上一张、下一张和张数指示，循环翻阅；原图片列表不改写，当前浏览位置随画布保存。大图预览也增加左右按钮。
- MJ 文生图前端、后台缺省值以及兼容入口统一为 8.2。已明确选择的 6.1 等版本继续保留；现有节点需要选择“使用默认”或 8.2 才会变更。
- MJ 提交前保存本地记录，包含画布、节点、参数；提交结果、任务编号、查询结果、文字和多图输出持续更新。不保存供应商 API Key。
- 生成记录合并普通任务、MJ 独立记录和当前画布已有日志，避免同一任务重复显示。取消统一任务列表静默截断至最近 300 条的限制。
- 历史面板查询 MJ 任务只查询原任务，不重新生成。切换图片不触发生成。

旧版只在部分成功操作结束后保存画布日志，没有可靠的完整 MJ 提交档案；本次可显示仍保留的日志，但无法恢复已被旧版截断、删除或从未写入的历史。新增持久记录从本次更新后提交的任务开始。

验证：9 项后台模拟测试通过，包含 301 条记录、画布隔离、任务查询更新、网络不确定记录与默认/显式版本；浏览器模拟测试通过多图切换、旧日志展示、默认版本与 MJ 主要操作回归。未调用真实付费模型。

更新后先保存画布，使用本目录停止入口关闭旧服务，再启动 DeepWhite Studio，刷新页面。不要在任务仍进行时强制停止服务。
