## 建议评审顺序

1. 首页：项目入口、最近资产、账号钱包与设备状态的布局是否清楚。
2. 创作画布：基础四类节点、素材缩略图、模型/参数/估价横排、图片处理入口。
3. 人物资产：效果图 → 用户提示词定义的灰底正式设定图 → 选择版本 → 确认为正式参考。
4. 场景与视频：360° 环境全景、反向与多角度、Seedance @ 素材、关键帧的入口。
5. 资产管理：候选/确认/归档、身份与版本、画布引用、项目文件夹之间的关系。
6. 执行来源：作者预置的本地工具与兼容模型、用户自有 RH 应用配置。
7. 后续功能：Agent 先预览建节点；导演/音频/发布更新按规划标注。

## 不应被设计误改的已确认规则

- 面向懂创作步骤的专业用户，自由画布不改为强制生产向导。
- “人物多视图”遵循用户自己的灰底三联设定提示词，不擅自换成普通正侧背模板；面板不展示固定提示词原文。
- 360° 全景是环境全景，不是宽幅裁切；反向镜头不是水平镜像。
- 不让普通用户接 ComfyUI 工作流；配置仅开放已兼容的模型与参数。
- 本地、API、RH 运行位置明确，不因本地失败自动转付费云端。
- Skill 库和通用工作流入口继续暂隐藏；以后技能作为 Agent 内部能力设计。
- 默认白色/黑色主题保持，牛奶白与炭灰暖金为附加主题；桌面优先，不设计手机版。
- 钱包余额、预估价与实际扣费区分；没有价格依据不显示为免费。
- 土豆产品截图/公开介绍、Fisher 代码参考、朋友的资产管理建议是三个不同来源，不将建议写成他人已实现的事实。

## 备份与恢复

备份位于 `本机本地路径`。
含本地 API 设置和项目数据，仅限私人保管。不是供他人下载的软件发行包。

需要恢复时，先停止正式程序及本程序拥有的任务，保留新产生的项目数据；将压缩包解压到一个新目录，核对 BACKUP-MANIFEST.json 后再切换使用。不要直接覆盖工作中的目录。当前备份不是经停服验证的事务快照。
