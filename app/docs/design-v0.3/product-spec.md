# DeepWhite Studio 产品设计说明

版本：产品设计 v0.3.0-design.1
编写日期：2026-09-24
当前程序版本：0.2.1-stage-one（此文档不代表程序版本已升级）
状态：设计基线，供交互预览评审；通过后再分阶段开发。

## 1. 产品定位

DeepWhite Studio 是面向专业短剧及叙事影像创作者的 AI 资产创作工作台。它以无限画布作为自由创作空间，帮助创作者调用 DeepWhite API、专业模型及经过预先配置的本地或 RH 工作流，制作并迭代人物、场景、道具、镜头等视觉资产。

产品的差异点是把短剧创作经验落到可直接使用的资产操作、参考关系、参数组织和制作辅助中。画布用户通常知道自己要完成哪一步，因此画布不强制规定从剧本到成片的固定顺序，也不把所有工作包装成自动工作流。创作者可自由添加节点、连接素材、试验和返工；资产提示、处理工具及专业模块帮助其更快完成具体工作。

API 是商业核心。平台应尽量降低专业用户使用模型的摩擦，清楚呈现可用模型、实际可估的费用、任务状态与错误原因。最终生成费用以 API 平台实际账单为准。

## 2. 设计原则

1. **自由画布为主**：节点可以按创作者自己的顺序组织。专业模块是可选工具，不强制套用统一流水线。
2. **功能统一、实现可替换**：用户围绕「人物设定」「场景角度」「图片编辑」等创作动作操作；底层可调用 API 模型、DeepWhite 预置本地工作流或用户配置的 RH 应用。
3. **工作流由产品方预先制作**：用户不需要在 ComfyUI 里连线或研究工作流。DeepWhite 负责维护并验证兼容工作流，用户只选择相应功能支持的模型并调整开放参数。
4. **尊重创作者素材**：原图不被覆盖；派生结果保留来源、版本和所用模型/参数。是否晋升为正式资产由创作者确认。
5. **自动化逐步增加**：先把单项创作和资产管理做可靠，再引入 Agent 批量分析剧本、建节点及执行操作。
6. **价格诚实**：只有有数据证据时显示价格估算；区间或近似值要标注依据和不确定性。未知价格不能显示成免费。
7. **账户统一**：目标是画布与 api.deepwhiteai.com 使用同一 DeepWhite 账号及余额。登录身份和 API 调用凭证属于不同权限，需由服务端安全衔接。
8. **设计参考分清证据**：AIFISHER、TDou 等产品用于观察公开可见交互或已检查的本地软件行为；未验证的内部实现不写成已知事实，也不照搬其专有内容。

## 3. 状态标记与当前基线

本文档使用以下标记：

- **已有**：DeepWhite 当前程序中已有入口或实现。若仅通过模拟验证，会明确写“模拟验收”；这不代表线上模型、费用或生产账号已验收。
- **待验证**：代码或流程存在，但仍需在用户正式环境核对、真实模型结果/账单验证，或覆盖边界情况。
- **规划**：产品方向已经讨论，尚未作为完成的产品功能交付。
- **暂缓**：保留在产品路线中，本轮预览不展开或不实施。

当前检查到的正式程序版本为 **0.2.1-stage-one**；本轮设计版本为 **0.3.0-design.1**。现有画布、API 配置、常用文本/图片/视频生成及部分资产处理已实现；账号登录、价格估算、ComfyUI 单图编辑等已有实现或模拟验收记录，但真实 API 站点在本环境返回 403，真实账号、钱包及实时价格尚待在可访问环境验收。用户明确选择本轮先交付完整设计和可交互预览，预览评审后再分阶段开发。因此本说明中的规划功能不能视为本轮已经添加到正式程序。

## 4. 产品信息架构

### 4.1 桌面主框架

**首页 / 项目工作台**

- 顶部：DeepWhite 标识、项目搜索、主题/偏好、API 设置、账户入口。
- 左侧：项目与文件夹导航；项目回收站；新建项目。
- 主区：项目卡片、最近打开、项目数量与继续创作入口。
- 账户卡：头像/账号状态、DeepWhite 钱包余额、刷新余额、充值入口、订单入口。
- 产品特性展示：短剧资产案例和关键创作能力动效或真实交互预览，不以装饰性假数据冒充真实项目。

**项目画布**

- 顶栏：返回项目、画布/资产库/日志/设置 API、账户钱包；ComfyUI 状态与开关固定在右上区域。
- 画布：自由无限画布、文本/图片/视频/音频节点、基础组织功能、素材连线及吸附。
- 节点操作：按当前功能显示紧凑模型选择、参数、费用估算及生成/运行按钮；失败时说明错误并允许修正后重试。
- 资产库：项目素材与正式资产的浏览、分类和复用入口。
- 生成记录：查看任务状态、输入、输出、所用模型和费用信息。

### 4.2 设置与管理

- API 连接：API 地址/密钥、连接测试、模型同步、启用/停用和余额刷新。
- 本地引擎：本地 ComfyUI 路径、启动偏好、状态、连接重试和日志。
- RH 应用：用户维护自己的 RH 凭证/站点和应用条目；每个应用声明支持的创作功能及输入/输出映射。
- 账户与版本：登录状态、账户余额、更新渠道、当前版本、查看更新及恢复说明。
- 资产偏好：默认命名、正式资产分类、项目目录位置和导出偏好。

本轮交互预览至少覆盖首页、一个项目画布、关键节点参数弹层、图片资产工具栏、资产库、API/账户、ComfyUI 控制和 RH 应用配置原型。需要明确显示哪些界面是预览状态、哪些是真实可用功能。

## 5. 创作对象与资产关系

### 5.1 对象定义

- **项目**：创作与素材的最高层容器。
- **画布**：项目内的一个自由创作空间，可多张画布；画布节点记录布局与连接。
- **节点**：在画布上的操作实例，例如图片生成节点或人物资产引用节点。
- **资产**：可在多个画布与制作步骤中复用的人物、场景、道具、声音、镜头等稳定对象。
- **文件**：图片、视频、音频、文本等实际媒体文件，可包含多个版本。
- **版本**：同一资产或文件的历史及派生关系；例如初始效果图、换装版本、正式设定图。
- **生成任务**：模型或工作流的一次执行记录，关联输入、参数、状态、结果和费用信息。

### 5.2 稳定编号建议

规划建立全局唯一资产 ID，并分别为项目、画布、节点、文件、版本、任务分配独立 ID。节点引用资产 ID 和版本 ID；复制节点沿用同一资产引用，不能误创建新人物。改图/换装/高清产生新文件或版本，并记下来源任务与父版本。

ID 是数据关联，不应要求创作者在日常操作中手工输入。界面展示可读名称，必要时在详情中查看编号。共享引用、删除保护、版本迁移和文件校验需要在正式数据结构方案中设计。

### 5.3 文件夹与画布的关系

这是 DeepWhite 的产品建议，来源于用户和朋友讨论，不归因于 TDou 已有能力。

- 画布服务创作试验；DeepWhite 管理的项目文件夹与资产库负责整理正式成果、查找、分类和交付。
- 上传和生成结果一产生就保存到 DeepWhite 管理的项目素材区、获得稳定文件/候选身份并显示在画布中；“确认”负责将它归属为正式人物、场景、道具等资产/版本，不是首次保存或首次显示的前置条件。
- DeepWhite 按稳定资产 ID、版本 ID 和文件 ID 组织项目受管目录；确认归档时按用户设定的类别与文件夹规则整理正式资产。
- 从资产库拖入画布时优先建立引用，保留来源关系；节点移动或删除不应直接删除正式资产文件。
- 正式资产的版本、来源任务、提示词和使用位置可追溯；更换当前正式版本前显示影响范围。
- 外部文件夹由用户显式选择后导入。软件扫描只建立导入候选；用户确认后将其复制到受管项目目录，记录哈希、原始相对路径和导入时间，不改写或删除外部原文件。
- 第一版实现 DeepWhite 受管目录整理与画布一致；用户直接在资源管理器任意移动/改名后自动识别、冲突合并及离线跨设备双向同步，后续单独评估。

## 6. 画布功能设计

### 6.1 基础节点

最重要的创作节点为文字、图片、视频、音频。工具、资产引用、对比、关键帧等作为基础能力或后续专用功能出现。暂不在新增节点菜单暴露 3D 世界、导演台、故事板等未完成模块。

图片节点必须有提示词；视频节点必须有提示词。节点可通过参考素材判断接口采用文生/图生等方式，普通用户无需区分底层 t2i/i2i 名称。模型选择按“模型系列 → 具体版本”呈现，厂商/平台调用选择统一位于模型选择区域。

对需要较多参数的 MJ 或视频模型，配置面板有足够默认尺寸显示常用参数；常用模型仍使用横向紧凑布局，将次要参数放入设置弹层。预计金额放在生成操作一排的末端，价格未取得可靠证据时展示原因而不隐藏整个区域。

### 6.2 连接及参考素材

- 节点边上的连接控件在选中节点后显示，鼠标进入端口周围一定范围时跟随或吸附；拖向另一个节点即可自动连线，无需点对点找端口。
- 支持类型校验、可取消预览和反向拖动限制；图片/视频等输入素材在目标节点内以缩略图/小图标显示，详细列表按需展开。
- Seedance 全能参考按 `@` 插入当前项目中可引用的图片、视频、音频等素材；界面显示稳定素材引用，生成时保持排列顺序。节点删除或资产更换时提供关联提示。
- 生成多张图片仍作为同一组结果保存在一个结果节点；左右浏览用于大图查看，不把每张图自动散落成独立画布节点。

### 6.3 画布整理

复用原画布具备的整理能力并验证其边界：整理全部、整理选中、按连线布局、分组/解除分组、复制、删除、撤销/重做、缩放至内容。整理只改变画布位置，不更改生成记录或资产身份。

## 7. 图片资产创作

所有上传或生成图片点选后使用同一张图片工具栏。工具栏按素材类型显示可用动作，例如人物调节、全景、画质、元素编辑、标注、更多；具体动作是否可用取决于连接的模型、平台和工作流能力。

### 7.1 初始资产提示词

专业创作者的困难之一，是从剧本中找齐需要的人物、场景和道具，并把每个对象写成稳定可复用的出图提示词。规划中由创作者先手动挑选资产或使用明确的分析工具，输出资产列表和提示词，再逐项/批量生成候选图。Agent 自动分析全剧本、自动建节点及批量执行安排到后续阶段，不作为本轮自动发生的行为。

### 7.2 人物资产

**标准人设图不是一般“多视图”按钮。**它是将一张候选人物图作为参考，使用用户提供的指定提示词，生成灰底人物设定图。该提示词要求特定三联版式（45 度头颈特写、正面无头全身造型、含头的完整背面全身等），保留原图并将结果作为新版本。固定模板由系统内部维护，标准人设图面板默认和展开状态都不展示提示词原文；界面提供案例图、模型选择、必要参数和价格估算。默认推荐指定 GPT 图片型号，同时允许用户选择兼容模型。

确认后的标准设定图作为正式人物参考图。后续可逐项添加：新服装、装备/物品替换、人物一致性处理、人物调节与版本对比。每项操作创建新结果且保留来源版本。

### 7.3 场景资产

- 从场景概念图生成 **360° 环境全景**，用于空间参考，而非普通宽幅图。
- 基于参考场景生成多个方向的视角与角度图。
- 一键生成反向镜头，遵守场景空间与画面方向连续性。
- 将同一场景的全景、正反打、角度图归并为场景资产的派生版本。

须标明每种能力依赖的模型/API 或本地/RH 工作流，场景一致性需要样例与验收。

### 7.4 图片编辑与细化

- 对话式涂改/局部修改，调用支持图像编辑的 GPT 或 Nano Banana 类模型。
- 对比节点同一节点中并排/滑块查看两张图片，支持选择任意项目图片；不应把“双图对比”拆成两个互不关联的节点。
- 一键高清/放大，保留原图及清晰度版本关系。
- 拆解重绘：通过经过验证的工作流把图片拆分为线稿与色块，再按提示词或参数重新绘制/组合。它不是单纯抠图或常规图生图，需明确各输出和回组方式。
- 裁剪、宫格裁剪、标注、尺寸调整、下载、大图浏览属于已有/基础编辑能力；每项编辑应支持新副本与原结果追溯。

### 7.5 Midjourney 专区

MJ 有独立功能和参数，不应合并为通用 GPT 图片节点里的几个通用选项。规划作为专用工具组：文生图、图片参考、风格参考码、角色参考、比例/版本/质量等参数，以及放大、变体、识图、局部重绘等由 API 实际支持的动作。

风格库通过公开资料和授权数据整理，再按模型版本、参考图、参数、提示词和结果记录形成 DeepWhite 自己的数据库。不得直接搬用 Fisher 的专有素材、测试结论或闭源数据。由于无法逐项自行试遍，应将证据来源、适用版本、用户反馈和置信状态一起展示。此专区列入设计，但近期暂缓扩大开发；准确 API 参数需逐型号核验。

## 8. 视频、声音与镜头辅助

### 8.1 视频节点

- 保留明确的视频提示词输入、模型/版本选择、参考素材、常用参数及费用估算。
- Seedance“全能参考”默认支持 `@` 选择素材，素材在提示词和请求中按创作者选定顺序关联。
- 视频模型按能力呈现首帧、尾帧、多参考等输入，不暴露底层协议模式给普通用户。
- 视频结果进入项目媒体库，可播放、下载、查看任务详情并提取关键帧。

### 8.2 关键帧与去字幕

关键帧：已有手动按视频时间定位、选择多个时点并导出原分辨率帧的功能；自动镜头切分和语义选帧属于后续扩展。

去字幕：规划为单独的视频处理动作，允许选定处理范围/轨道并预览结果，尽量保留画面主体与其他影像信息。需要先确定采用 API、预置本地工作流或用户 RH 服务，以及是否只消除画面字幕或也处理字幕轨；不能默认删除对白音轨。

### 8.3 音频

音频是主要媒介节点之一。基础范围包括上传、播放、项目素材引用和作为模型参考；音频生成、配音、音乐/音效生成及字幕/转录能力需要按可用 API 与费用单独规划。只可在接口适配后将生成能力标为可用。

## 9. 3D 导演台、站位与分镜

### 9.1 3D 导演台与 Blender 白模

规划通过简易空间界面布置人物、场景和相机，以基础几何白模检查景别、视线和调度，再连接 Blender 白模预演。不要求普通画布用户学习 Blender 工作流。Blender 本地整合包和已有工作环境是后续选项，需先确定分发、资源体积和许可证。

导演台记录场景、角色位置、镜头机位/方向及关键帧；它是帮助创作者验证空间关系的工具，不替代最终美术场景或表演成片。

### 9.2 站位图与俯视图

将角色、镜头和空间关系转换为站位图/俯视图；可视化人物移动轨迹、轴线、机位和出入口。与画布节点互相链接，并能回到使用的角色与场景资产。准确性和字段格式需要随 3D 导演台原型评审确定。

### 9.3 分镜与剧本

分镜、剧本创作是最终产品范围，但用户倾向后期再加入。近期以已确认剧本/镜头需求作为资产制作输入；以后再做剧本创作、场次拆分、镜头规划与资产引用，且应允许专业创作者编辑而非强制自动采纳。

## 10. 本地工作流与 RH 应用

### 10.1 本地 ComfyUI

DeepWhite 产品方维护干净、经过验证的整合工作流。工作流的连线、依赖模型、固定设置、输入输出映射对普通用户隐藏。用户在功能节点的配置按钮里选择该功能支持的本地模型、可修改参数及默认选项，启动/关闭 ComfyUI 状态常驻显示。没有本地能力时用户仍可选 DeepWhite API。

一个工作流配置至少包括：唯一 ID/版本、支持功能、ComfyUI 模型与节点依赖、提示词/图片等输入映射、可编辑参数的 schema、输出类型与提取规则、错误分类、费用类别（本地计算/无 API 扣费）、兼容性检查与样例。工作流升级需要版本化，旧任务仍记录原版本。

现有本地 Qwen 单图编辑适配可作为后续设计样例，但它只针对已知工作环境，并不意味着已经具备通用导入或打包分发能力。

### 10.2 用户自己的 RH 应用

用户可以在设置中添加/管理 RH 应用，配置站点和个人凭证，再为应用指定创作功能。应用适配表描述提示词、图像/视频输入、参数、结果字段和状态查询方式。若 RH 无法提供可靠元数据，提供显式手动字段映射和保存前试运行；试运行需由用户触发，不能暗中产生付费任务。

凭证应安全保存，不在日志、画布数据或导出文件中明文出现。画布只选择已配置应用；显示运行状态、任务链接/编号、结果、费用信息（只有 RH 数据可验证时）和错误原因。

## 11. 账号、API 商业与软件生命周期

### 11.1 共用账号和微信登录

目标为 API 网站与 DeepWhite 画布使用同一账号、同一钱包身份。先实现账号密码或可用的授权登录并安全查询身份余额；微信扫码属于进一步目标，要求网站服务端支持微信身份绑定/注册、一次性登录授权和桌面应用凭证交换。

统一账号不等于前端复用网站 Cookie。生成密钥/API 调用凭证应由服务端或本机安全存储隔离管理，权限最小化，可撤销和轮换；登录状态、钱包余额、API Key 权限分开显示。真实账号共用需 API 服务方支持并在正式环境验收。

### 11.2 钱包、计价和用量

- 首页显示当前登录用户钱包余额与刷新时间；未登录时提供登录入口。
- API 生成仍走 DeepWhite 账单；费用估算清楚写人民币/平台计价单位及数据时间。
- 先匹配相同模型与参数下的价格证据；近似匹配要显示“估算”与不确定范围；无证据则显示“暂无可靠估价”。实际结算金额以 API 账单为准。
- 本地 ComfyUI 运行不扣 DeepWhite API 额度，RH 任务的费用以 RH 平台实际账单为准。
- 不利用 Fisher 的售价。可借鉴其参数识别/近似匹配方法，但全部金额须来自 DeepWhite 或当前用户服务的可验证数据。

### 11.3 桌面打包与自动更新

未来桌面版需可安装、可卸载、用户数据与程序升级分开、首次启动能管理本地后台生命周期。ComfyUI 模型包可作为用户选择的附加下载项，避免每次升级重复下载。

自动更新建议包括：版本通道、更新说明、数字签名/哈希校验、下载进度、磁盘空间检查、旧版备份、失败回滚、保留项目与凭证、跳过/稍后更新以及诊断日志。首发先完成人工发布与更新检查，再逐步自动下载安装。该能力尚未交付，且不能仅凭 Fisher 安装包外观断言其内部全部实现。

## 12. Agent 与 Skill（后续暂缓）

目标参考已观察到的 Agent 工具调用方式：读取当前画布、理解用户要求、提出结构化编辑计划、按授权创建/修改节点、读取工具结果继续工作，生成任务经过授权与状态追踪。未来可用于剧本资产拆解、提示词整理、批量创建节点、查找未确认资产及辅助归档。

Skill 是提供给 Agent/文本生成的专业操作说明和资源，不应被误认为自动化本身。Agent 使用 Skill 的步骤、输入上下文、工具权限和风险动作仍需另行架构设计。

本轮预览不展示可执行 Agent 或 Skill 库入口；暂缓向用户开放，直到画布工具协议、权限确认、变更预览/撤销、用量提示和审计记录设计完成。不得复制 Fisher 闭源 Skill 或脚本。

## 13. 关键创作流程

### 流程 A：创建并确认人物资产

1. 在自由画布添加图片节点，输入人物效果图提示词，选择可用 API 模型或已配置本地能力并生成候选。
2. 点选满意图片，从图片工具栏执行「标准人设图」。
3. 软件使用用户指定的三联提示词，以该单张候选图为参考，提示预估价格并生成独立结果。
4. 创作者检查灰底设定图的一致性与构图，确认后保存为人物资产/版本。
5. 人物可继续新增造型、装备或道具变化，结果可回看、对比、复用。

### 流程 B：场景空间资产

1. 生成/上传场景概念图并确认场景身份。
2. 生成 360° 环境全景和多个方向视图；需要时生成反向镜头。
3. 用角度图连接到镜头节点或 3D 导演台，验证方向连续性。
4. 确认图归档到同一场景资产的版本/视角下。

### 流程 C：本地工作流创作

1. 在右上打开本地 ComfyUI，等待引擎状态就绪。
2. 在图片编辑等创作节点选择本地平台，再打开节点配置选择兼容模型与已开放参数。
3. 输入修改提示、连接/选择参考图并生成。
4. 画布显示本地任务状态、结果和来源；确认后进入资产库，不扣 API 钱包额度。

### 流程 D：使用用户 RH 应用

1. 在设置中添加 RH 应用与凭证，声明它用于什么创作动作。
2. 映射提示词、参考素材、参数与结果，保存前显式试运行。
3. 在画布功能配置中选择该 RH 应用，提交后呈现平台任务状态/结果。
4. 估价仅在平台返回或有充分数据时显示，否则提示去 RH 核实账单。

## 16. 非目标与风险

- 画布不是强制标准流程编辑器；批量工作由后续可选 Agent 提供。
- 本轮不实施产品预览外的正式功能，不启用真实付费生成。
- 不把本地 ComfyUI 工作流暴露成通用“任意 JSON 导入”功能给创作者；技术编辑仅供 DeepWhite 内部或高级运维。
- 不默认把用户全部剧本、资产上传到云端；云端同步和隐私范围要单独确定。
- 不假设 API 平台已有微信 OAuth、桌面授权码、价格字段或 RH 元数据端点；需服务提供方核实。
- 本地模型、Blender 和整合包需考虑文件体积、硬件兼容、许可证、升级策略与售后支持。
- 自动分析或批量生成可能产生较高费用；以后需在确认执行前展示任务数量、预计费用和生成来源。
- AI 生成的人物/场景多视角存在一致性限制，必须以实际模型输出和人工确认作为正式资产门槛。
