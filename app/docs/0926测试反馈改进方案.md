# 0926 测试反馈改进方案

日期：2026-09-26。依据：反馈/0926.docx 的正文及 6 张内嵌截图，以及当前 Agent、即梦通道、本地目录设置代码。此文为改进方案，没有发布新程序版本，也没有把待复现的问题标为修复完成。

后续实施记录：用户确认后已按本方案开发 0.9.0-feedback.1，实际完成范围、验证和剩余边界见[本版说明](releases/0.9.0-feedback.1.md)。下文保留制定方案时的判断。

## 判断

基础画布已能承担创作，但当前入口组织、账号生命周期、状态反馈和 Agent 形态需要集中调整。建议先修故障，再统一交互，最后把助手改为可见的 Skill 节点执行。MCP 在本次用户测试中未测，继续标为未测。

本次反馈覆盖两项旧需求：双图对比改为工具功能，不再默认新建节点；Agent 改为剧本、Skill 运行、生成节点之间的可见链路。历史对比节点和历史聊天记录仍需兼容，不能直接删除用户数据。

## 逐项处理

| 项目 | 建议处理 | 验收标准 |
|---|---|---|
| 双图对比 | 选中两张图或从左侧工具打开对比面板；不新增画布节点。旧对比节点保留读取兼容 | 打开、切换图片、滑块对比、关闭均不污染画布 |
| 主题切换颜色错误 | 排查主题残留类、内联颜色及浮层样式；建立统一主题变量 | 四主题连续往返、刷新、重开浮层后颜色一致 |
| 模型菜单 | 主入口保留模型系列与“本地 ComfyUI”；云端系列内选择版本，再选择实际支持的调用通道 | 先找模型再找通道；只出现支持当前型号的通道，不能把同名产品当作等价型号 |
| 平台设置 | 统一为“设置 → 模型与连接”，包含 API、即梦、本地 ComfyUI，未来再接入小云雀；各连接卡片内测试 | 连接测试集中，生成节点不承担账号配置 |
| 原智能画布 | 新建入口隐藏未整合的原智能画布；已有画布继续可访问 | 新用户只有明确的普通画布入口；旧数据不丢失 |
| 即梦费用 | 已有积分余额查询不等于单次任务报价；先核验 CLI 是否提供参数报价和任务扣分数据 | 可查则显示预计积分/实际积分；不可查明确未知，禁止用固定假数或把积分冒充人民币 |
| 登录后头像与钱包 | 用户区展示昵称与可用头像；余额做成简洁账户卡，标注单位、刷新状态和充值入口 | 有头像显示真实头像；接口未提供时用首字/默认头像，不编造数据 |
| 左侧工具栏 | 移走顶部的大型节点创建栏；左侧放对比、截帧、图片处理等工具。双击/右键菜单负责新建文本、图片、视频等节点 | 不再两套相同菜单；只有具备适用素材的处理工具才可执行 |
| TXT 上传 | 拖入或上传 TXT 后读取文本，生成可编辑文本节点并使用文件名作标题 | 中文正常；保存重开内容不丢失；大文件或编码异常有说明 |
| 即梦重复登录 | 分开“停用通道”“退出账号”“重新授权/换号”；核验 CLI 实际退出能力，清理本次授权与轮询状态 | 首次授权、退出、再次授权、换号、取消及过期均可完成；旧任务不以新账号错误查询 |
| 连线断口 | 统一连接端点与节点边界坐标，覆盖缩放、拖动、尺寸改变 | 线真正抵达连接点，不能靠延长装饰线掩盖错误 |
| 连线强调 | 默认低对比；选中节点时突出关联线；方向流动为可选设置 | 未选中不抢视觉；选中关系清楚；关闭动画后仍能读懂方向 |
| 图片节点比例 | 媒体展示区随原图比例变化；工具标题区独立；极宽/长图限制整体尺寸 | 不拉伸、不用固定正方形制造大留白；缩放和连线位置同步 |
| 生图数量 | 数量选择移到外部操作行，靠近估价和生成按钮 | 直接调数量，报价联动；不支持多张的模型固定 1 |
| ComfyUI 状态与进度 | 顶栏精简引擎状态；任务进度放在生成节点，显示排队、载入、采样、保存等阶段 | 有真实进度才显示百分比；无总量显示阶段，不制造假进度 |
| ComfyUI 主模型与参数 | 为已接好的工作流定义可选参数和兼容模型清单，配置按钮里选择 | 仅列兼容且存在的模型；固定连线不暴露给用户；不支持项不能随意替换 |
| 选择文件夹卡住 | 排查原生窗口在后台、返回超时及全表单禁用问题；目录选择取消也应恢复交互 | 系统选择窗口可见；选中即确认选择；取消/失败不锁死。空项目可直接保存；已有素材需明确迁移过程 |
| Agent 太繁琐/没有创建节点 | 采用下述可见节点方案，精简侧边助手；区分普通答复与节点任务，不能把纯文字答复当完成 | 剧本节点、Skill 运行节点及生成节点形成完整链路；视频素材正确绑定 |

连线原文有“点击/未点击”的表述重复，此处按上下文理解为“未选中淡化、选中强调”。实施前可用交互预览验证，不把这一解释当作已经确认的视觉效果。

## Agent 的重新设计

用户路径：导入剧本 → 文本节点 → 选择处理技能 → Skill 运行节点 → 输出各资产生图节点；视频任务则连接已有资产，并生成带提示词和素材映射的视频节点。

Skill 运行节点只突出：技能名称、输入资料、补充要求、开始分析/继续修改、执行状态。对话模型和高级设置折叠；默认沿用项目偏好。侧边栏用于选中该节点后的多轮对话与结果复核，避免同时堆出模型、技能、素材 ID 和所有附件。

建议首次生成节点方案后提供“创建这些节点”；再次修改时根据稳定编号更新原节点，不能每一轮都新增副本。用户主动开始任务即授权分析；图片和视频的真实生成仍单独执行或按授权规则确认。创建节点与产生媒体费用分开表达。

实现上保留已有会话、方案校验、资产版本引用、批量写入与撤销能力，新增文本源节点和 Skill 运行节点的持久化关联。每次运行保存输入版本、所用技能版本、方案、输出节点清单和状态。依赖连接与媒体参考连接需要明确区分，避免把“Skill 节点连到图片节点”误当作图片素材。

失败、模型只返回聊天文字、结构不合格或未绑定目标模型时，显示具体原因及可继续操作；不能宣称已创建节点。对已生成的节点进行修改时保留旧结果，不自动重新收费生成。

## 已看到的代码证据与待确认项

- Agent 的方案写入接口已存在，支持图片/视频节点，但方案允许为空，目前结构没有文本源与 Skill 运行节点。不能仅凭聊天截图断言后端完全不会创建节点；应检查本次对话是否产生有效方案及前端是否展示确认入口。
- 目录选择前端会锁定整块表单，等待选择接口返回；选中后还要求另点保存。后端已有原生文件夹选择器。这能解释部分体验问题，尚不能证明具体卡住原因，需要复现窗口前后台与取消/超时。
- 即梦代码已有登录、授权轮询和积分余额查询；目前未看到完整退出流程。停用通道不是退出 CLI 账号。
- 主题残色、连线断口及图片留白有用户反馈/截图证据，尚未完成本机复现和根因定位。
- 即梦单次报价、网站头像字段与 ComfyUI 当前主模型替换范围，需核验实际接口/工作流，不提前保证支持。

## 实施顺序

1. **修复阻塞与错误：**目录选择、即梦退出及重复授权、主题切换、连线端点。逐项真实操作验收，不依赖模拟测试结论。
2. **统一常用操作：**左侧工具栏、对比工具、上传文本、图片比例、外部张数、模型/通道选择、账户卡片、设置分组和新建画布入口。
3. **Agent 专项：**先给可交互的三类节点预览，确认操作逻辑，再连接现有方案执行层，验收剧本资产与视频素材两条完整链路。
4. **补通道能力：**ComfyUI 工作流参数/主模型及真实进度、即梦报价能力。无法查询的价格继续明确未知。

每个实际发布版本继续提供独立更新文档、累计未完成清单与测试记录。本次仅形成方案，不修改版本号。MCP 先保持接口兼容，待 Agent 节点定义稳定后再扩展对该节点的控制。
