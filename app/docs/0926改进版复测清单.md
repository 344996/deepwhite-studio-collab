# 0926 改进版复测清单

适用：0.9.0-feedback.1。请新建测试用普通画布，不在设计预览页验收。下面主要测试本次变化；历史手册中“创建对比节点”的操作以本清单替代。

| 顺序 | 操作 | 应看到什么 |
|---|---|---|
| 1 | 在白、黑、牛奶白、炭灰暖金之间反复切换；再从设置切换白/黑 | 返回某主题后颜色一致；节点、菜单和弹层没有残色 |
| 2 | 查看画布左侧工具，再双击空白处 | 左侧是按需处理工具；双击是新建节点，菜单不重复 |
| 3 | 拖入 TXT 文件 | 出现可编辑文本节点，中文正常，刷新仍保留 |
| 4 | 上传一张宽图和一张竖图 | 媒体区域匹配图片比例，不拉伸，也没有固定方框造成的大留白 |
| 5 | 连接两个节点，拖动、缩放并改变大小 | 连线抵达节点；选中时关联线强调；方向动画可以关闭 |
| 6 | 选中图片，打开“双图对比”，选择两张图片，移动滑块并关闭 | 是工具面板；画布没有新增对比节点；原有旧对比节点仍能打开 |
| 7 | 在生图节点选择模型 | 先系列、再版本、再可用调用通道；本地 ComfyUI 单列；不要求手选 t2i/i2i |
| 8 | 查看外部张数选择，改变张数 | 无需打开参数浮层；估价随支持的参数更新。未知费用不等于零元 |
| 9 | 设置 → 模型与连接 | 可以进入 API 配置、即梦账号与本地 ComfyUI 设置 |
| 10 | 登录 API 账户，打开账户信息 | 余额卡与网站单位一致；有头像数据时显示头像，否则显示默认首字头像 |
| 11 | 选择测试项目的保存目录，再取消一次选择 | 选择窗口可见，取消不会锁住页面；选中后直接确认，已有素材会先提示迁移 |
| 12 | 即梦授权、退出、再授权；中途取消后再开始 | 能反复操作；停用通道与退出账号不同；有未完成任务时明确阻止换号 |
| 13 | 本地 Qwen 节点打开设置 | 显示已发现的兼容主模型、采样步数、CFG 与提示词优化；没有安装的其他架构不混入 |
| 14 | 明确准备运行本地任务后生成一张 | 节点显示排队/运行阶段；收到真实采样数据时显示阶段百分比，完成后保存图片 |
| 15 | 打开画布助手，上传短剧本并选择资产拆解技能 | 剧本以文本节点保留；高级参数默认收起；首次使用可展开选择对话与目标模型 |
| 16 | 要求分析资产并创建生图节点方案；检查后确认写入 | Skill 运行节点与输出节点形成可见处理关系；每项资产有对应生图节点，提示词已填写 |
| 17 | 再要求修改其中一个人物设定 | 复用相应输出节点、保留已生成结果；不因修改提示词自动收费生成 |
| 18 | 选择人物、场景资产，让助手提出视频节点方案并写入 | 视频节点有提示词、素材连接和正确 @ 引用；技能说明没有混进生图/视频输入 |
| 19 | 对新建方案执行撤销，保存后重开画布 | 撤销范围正确，节点和关联信息可持久化 |
| 20 | 如已配置 MCP，用外部智能体创建节点并申请生成 | 保持逐次确认；结果回写不引发无意义草稿冲突，查询不重新提交 |

第 10、12 项需要真实账号；第 14 项使用本机显卡；第 15～18 项对话可能计费；第 20 项批准生成可能计费。先做不生成的检查，再自行决定真实调用。

即梦当前积分余额与单次预计消耗分开：单次价格缺少可靠查询接口时仍显示未知。小云雀、RH 完整应用配置、通用 ComfyUI 工作流、自动更新等不在本次已实现范围。

反馈时提供：步骤编号、使用通道和型号、操作顺序、预期/实际结果、截图、任务编号及是否扣费。不要提供密钥。
