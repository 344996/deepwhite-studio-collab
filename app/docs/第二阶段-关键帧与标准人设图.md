# 第二阶段：关键帧与标准人设图

2026-09-19，第一批两项工具。入口位于正式普通画布中的图片/视频素材，以及生成结果中的对应单张素材。智能画布暂未接入这两个入口。

## 标准人设图

1. 单击上传图片或生成结果中的某一张图片，在图片上方的悬浮工具栏点击「标准人设图」。
2. 核对参考图、模型和估价。默认「全能图片 G2.5 · 高品质版」（`deepwhiteai-image-g-v2.5-sunburst`）。若未启用，必须先启用或手动选其他支持参考图的 G 系列型号，不自动降级。
3. 可展开查看提示词原文。点击「生成标准人设图」才会调用 API。
4. 创建独立的标准人设图生成节点，复用已有生成、费用、错误提示、记录及恢复机制；原图不被覆盖。结果可继续接到其他节点。

提示词原文复制自用户提供的 `本机本地路径`，保存于 `static/prompts/standard-character.txt`；未改写文案。包含：45 度头颈特写、正面无头全身造型、含头完整背面全身、灰色背景与人物一致性要求。固定 4:3、1K、单张，仅发送所选图片作为人物参考，不发送整个多图节点。真实人物一致性及三联构图效果仍需模型实际出图后确认。

## 图片上方的统一处理工具栏

上传图和生成图采用相同交互：单击图片显示工具栏，双击或点击「查看大图」打开大图，点击画布空白处收起。多图结果中仅处理当前选中的那张图。

首批入口：标准人设图、裁剪、宫格裁剪、标注、调整尺寸、下载、查看大图。工具栏保持屏幕尺寸并跟随选中图片位置；原画布编辑器继续承担裁剪、宫格、标注和尺寸调整。对生成结果编辑时先建立独立图片副本，保留原结果集合，支持原有撤销操作。后续处理工具逐项增加。

## 截取关键帧

1. 在上传的视频或生成视频结果上点击「截取关键帧」。
2. 播放/拖动播放器定位，也可输入秒数点击「定位到此时间」。
3. 点击「添加当前时间点」；可以选择多个时间点，重复时间不重复添加，点时间标签可移除。一次最多 20 帧。
4. 点击「保存关键帧到画布」，在本机解码视频并保存原分辨率 PNG，多个结果放入一个节点，保留来源视频与时间点信息。

截帧不调用生成 API。使用浏览器支持解码的完整视频；不支持的编码、缺少有效时长或受跨域限制的媒体会提示处理方式。定位精度由视频实际帧率与浏览器解码决定；第一版是手动选择关键画面，不包含自动镜头检测、自动识别语义关键帧或后台 FFmpeg 批量任务。

## 验证

`tests/check-media-tools.cjs` 使用隔离画布和模拟生图接口：验证默认型号、提示词原文、唯一参考图、比例、单张、原图保留、保存重开不重复提交。

截帧采用实际录制的红/蓝 WebM 视频，真实执行浏览器解码、定位、PNG 导出与本地上传；检查两个时间点的画面颜色、尺寸、数量及保存重开。验证过程未消耗真实生成额度。
