- 范围：智能画布缩放时的编辑与工具条、经典画布手势性能、尺寸撤销及异步切换保护。

## 本次新增与修复

智能画布的选中编辑卡和浮动工具条保持正常屏幕尺寸，节点与连线仍按画布比例缩放。编辑卡显示所属节点，可定位回该节点；靠边、适合画布和素材面板打开时调整布局。长提示词、上游文字、参数区分别滚动，模型、参数和 `@` 菜单保持可操作。保留原输入 DOM 和处理链路，不因布局变化重挂正在编辑的输入框。具体操作见[画布缩放与编辑](../../../docs/画布缩放与编辑.md)。

经典画布的平移、节点拖动、尺寸调整和框选越过移动阈值后使用专用输入层，避免全页面反复应用禁选样式；结束、失焦和取消后释放。普通单击、多选、连线、刀具和导航仍沿原事件路径。整理按钮只计算组的数量，实际整理仍读取几何信息；框选期间不再计算连接悬停。

修复节点尺寸调整没有撤销记录的问题：首次实际尺寸改变前保存一次历史，同一手势不重复记录，零变化不新增历史。

修复异步打开画布的混合状态：等待期间旧画布可以继续交互，但新画布发布前取消旧手势并处理未保存内容。保存失败或保存期间继续修改时保持原画布；过期的打开请求不覆盖最新选择。画布对象、节点和连线同时发布，旧素材检查和晚到鼠标事件不能改写新画布。

## 性能证据

基线在修改前从 `7b7b0cb` 的 300 节点隔离页面采样；修改后使用相同脚本、数据和 Edge 154.0.4258.53，在没有其他测试浏览器并行的窗口复测。以下为该次采样的浏览器长任务（≥50ms），不是逐帧时间：

| 操作 | 修改前最长 | 修改后最长 | 长任务数量 / 合计时间 |
|---|---:|---:|---|
| 平移 | 207ms | 未出现 | 2 / 411ms → 0 / 0ms |
| 框选 | 214ms | 未出现 | 2 / 416ms → 0 / 0ms |
| 拖动节点 | 235ms | 57ms | 2 / 415ms → 1 / 57ms |
| 滚轮缩放 | 77ms | 111ms | 8 / 492ms → 4 / 286ms |

样式计算的最长片段分别从平移 190.20→12.71ms、框选 185.27→2.25ms、拖动 161.52→5.91ms。整理按钮在平移、缩放和拖动中不再调用全图 `nodeRect`；框选不计算连线悬停，导航地图同步布局读取为 0。另一份完整空间检查覆盖 100/300 节点，300 节点的三次同页重新打开约 2.26–2.32 秒。

滚轮缩放的单次峰值反而上升，虽然累计长任务减少，仍保留卡顿问题。剩余开销主要包含连线绘制与端口几何查询。单机短时采样不是低配、数小时稳定或全程 60fps 的承诺。原始报告位于系统临时目录 `deepwhite-classic-pan-drag-profile-final`，完整空间检查副本为 `deepwhite-canvas-performance-review/classic-pointer-final-result.json`。

## 尚未实现与下一步
