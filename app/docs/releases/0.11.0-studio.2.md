# 0.11.0-studio.2 · 生成记录界面完善

- 日期：2026-10-20。
- 基于：0.11.0-studio.1；画廊仍为 0.4.0 / schema 4。
- 类型：功能修订，源码及本机预览；本轮未生成新的发行包或公开更新。

## 本次新增与修复

重新对照 1020.docx 第 9 项文字和附图，统一经典、智能画布的生成记录：大图结果卡片、状态徽标、可读提示词、时间与真实费用分层、折叠参数和完整提示词；统一下载、放入画布和复用位置。

增加类型快捷筛选、重置，以及空记录、筛选无结果、加载和重试提示。适配小屏与键盘，关闭记录时停止媒体播放；避免关闭/重开过程中旧请求覆盖新记录。详细需求映射、修改入口和验证见 [第 9 项交付说明](../../../docs/生成记录界面-1020第9项.md)。

## 当前版本累计功能

见 [本版完整累计状态](0.11.0-studio.2-status.md)。完整继承 0.11.0-studio.1 的能力与缺口。此次只改变记录展示和相关交互，MCP、登录/API、保存、画廊和更新能力沿用前版；微信仍暂缓。

## 使用与验证

画布 → 生成记录。新增 18 组专项、原 8 组 UI 回归、MJ 历史回归与 JavaScript 语法检查通过。使用真实本地引擎、模拟记录和本地样片；没有外部或付费生成请求。此前后端和便携发行验证不计作本次重跑。

## 数据兼容、备份和恢复

画布 schema 1，无数据迁移；不清理旧作品和生成记录。备份范围仍为 userdata 和所有外部媒体；恢复旧代码前先停止服务并另存最新数据。没有以界面回归宣称生产完整回退或第三方媒体链接全部验收。
