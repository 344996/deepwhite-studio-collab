## 本次新增与修复

经典画布自有 API 文字、聊天、视频以及智能画布文字、视频入口增加固定任务记录。请求包括原画布、源节点、输出节点和输出槽；保存并 GET 回读确认后才提交。修改提示词、模型、切换项目或更换同编号节点，不会改变已提交快照，也不会把晚到结果写入新目标。

智能文字生成期间关闭 LLM 并手写新稿时，原回复保留在任务卡中供查看、复制或显式替换，手写内容保持不变；替换可以撤销。经典聊天清空或修改对话后，旧回复同样不自动插入新对话。任务记录保留，较早任务不能解除较新任务的运行状态。

智能视频固定素材映射后再等待任务；手动映射优先于临时云端缓存。任务结束仅清理开始时捕获的临时链接对象，保留等待期间新增或替换的链接，避免旧任务清掉新的上传地址。

视频区分“远端生成完成”和“本地结果保存”。收到供应商回执立即写账本；重启后普通查询只读记录，显式“继续查询”才读取原远端任务。已有结果下载失败时，保存地址和原结果，只重试转存，不再提交生成。缺少回执的中断任务显示待核实；空文字或无法解析的提交响应不再伪装成功，也不会自动尝试另一生成端点。

任务卡默认展示最近一次，另外五条最近记录折叠显示，并注明历史总数；项目中的原记录保留。展开和滚动位置在重绘后保持。结果窗口直接提供文字或视频预览、复制与下载；原输出被删除后仍可查看源节点中的结果，查询不会自行重建输出。

智能通知移到顶部栏下方，保持输入焦点，沿用共享主题与减少动效设置；文字节点输入框修正四种主题下的底色和对比度。默认尺寸节点内的任务卡可滚动，滚轮不会同时缩放画布；有任务卡且媒体内容溢出时，也可以从媒体区域滚到下面的任务操作。浮动工具条按可用空间避让节点、编辑卡和小地图；“适应画布”预留编辑区随参数高度调整，新任务卡的实际范围计入避让。旧后端缺少任务能力时明确提示需重启载入更新，并停止新入口提交。操作见[文字与视频任务恢复](../../../docs/文字与视频任务恢复.md)。

## 协议及恢复边界

| 路径 | 本版行为 | 限制 |
|---|---|---|
| 标准 HTTP / 既有 CLI 文字 | 一次固定提交，返回结果持久保存；原请求可只读查询 | 同步调用中断且无结果时无法补回文字；裸异步 ID 不视为已适配查询协议 |
| 通用 HTTP、Agnes、土豆、Grok 视频 | 保存原协议/地址/任务号，显式查询原任务；Grok 内容下载沿用认证接口 | 各真实供应商尚未付费验收，不保证所有未知返回格式 |
| RH 标准视频模型、即梦视频 | 保留实际回执，查询或保存原结果 | 不包含原生直接 RH/MiniMax 工作流；即梦外部 CLI 重登录账号变化无法可靠识别 |
| 深白适配子任务 | 派发前固定子请求身份与指纹；父回执丢失仍只能读取已有子任务或查询已知远端回执 | 缺失或未提交的子任务不会在恢复时自动补交 |
| HTTP 渠道绑定 | 绑定地址、模型协议和实际凭据指纹；改变配置后阻止错渠道执行 | 原始密钥不进新增账本，指纹不公开；CLI 登录态没有可靠账号标识，需核对原账号 |

新增 GET 接口不启动生成或远端轮询。初始执行和恢复使用任务锁；不把有限并发测试理解成长期、多机协调验收。旧无 request_id 的直接客户端不因此获得前端请求幂等保证。

画布复用追加的 `studioLegacyAttempts` 和输出待办字段，原数据无需批量迁移。新增本地任务账本位于运行数据目录的 `studio_legacy_tasks`，深白子任务沿用已有生成账本；不把模拟数据写入用户项目，不覆盖旧程序或用户作品。源码基线为 `df5603a`；本轮没有新增生产数据库/媒体备份，不以 Git 代替用户数据备份，没有生产重启或恢复演练。回退代码前需保留运行数据及新增账本，旧版本不提供新任务恢复界面。
