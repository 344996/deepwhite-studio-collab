## 使用与验证

从源码启动使用根目录 requirements.lock.txt 和 app/studio_server.py。便携包完整解压后运行 Start.cmd；默认本机3848端口，可通过 installation.json 配置。

更新入口：设置 → 基础设置 → 关于 → 版本更新、安装与回退。先保存并关闭其他画布页，处理所有未完成或待核实任务，再确认安装。

当前验证结果和证据入口见[本轮交付报告](../../../docs/交付与验证-20261019.md)。测试用隔离数据、合成账号/媒体和 mock 上游；真实客户端联调只读取编辑，无模型推理和生成扣费。可执行包、在线发布读取和 mock 清单演练分别记录。

## 数据与回退

程序放 versions/，本机用户数据在 userdata/。安装前停止自有服务并取得数据锁，备份全部 userdata 与 SHA-256 清单，成功提交后才解除维护。旧程序版本保留。

新版本启动失败时恢复更新前数据；成功后的手动程序回退保留最新 userdata。未知事务、签名失败、磁盘不足、占用或未知数据 schema 拒绝继续，故障目录不删除。当前数据schema1，不开放跨schema迁移。外部素材目录只保留引用，需另行备份。详见[更新维护文档](../../../docs/Windows发行与更新.md)。
