# 0.10.2-studio.11 第一批安全保存与操作修复

- 日期：2026-10-17
- 类型：独立源码测试副本；没有向原仓库提交、推送或发布安装包。
- 基于版本：0.10.2-studio.10，源码提交 d59a0225f5a0329e5dee7e888b96cbab71b0621e。
- 本次范围：安全、保存及画布核心操作。保持现有布局和生成引擎。

## 本次修复

1. 新旧 API 设置统一绑定地址与密钥。地址变化、删除后重建平台、自定义图片接口换域名时，不再默认复用旧凭证；RunningHub 钱包密钥、火山副密钥和显式输入新密钥的路径也纳入检查。WebSocket 握手独立验证本机 Host 和 Origin。
2. 智能画布按修改版本确认保存，旧响应不会将新修改误标成已保存；原生保存期间的编辑会补存，失败仍保留草稿和重试入口。返回列表会等待保存完成，等待期间继续编辑或保存失败时留在画布并提示重试。原正式页面已经有外层保存队列，本次不把原生入口的问题描述成正式页面必然丢失数据。
3. 项目索引采用临时文件、刷盘和原子替换，并保存上一版有效备份。损坏时停止覆盖，首页提供明确提示和显式恢复；恢复前保留损坏文件。项目删除时的画布迁移、画布元数据修改同样采用原子替换。多个画布迁移中途失败时保留项目索引，重试继续剩余工作。
4. 资产 SQLite 初始化完成或异常后立即关闭连接，避免 Windows 数据库文件一直被占用。
5. Alt 拖拽复制及移动成为一次撤销操作；Alt+Shift 复制的输入连线一并撤销。提示词只在实际修改时记录历史，单纯进入输入框不清空重做。
6. 两种画布中，文本框和可滚动面板优先处理自身滚动；纵向滚轮连续缩放，Shift+纵向滚轮水平平移，含横向位移的触控板滑动按两个轴平移，Ctrl/Meta+滚轮或捏合以指针为中心缩放。零位移不缩放。经典画布范围保持 6%–250%，智能画布与其按钮统一为 6%–200%。

## 使用与验证

详细最终计数、日志和复测方法见根目录[第一批修复说明](../../../第一批修复说明.md)。新增测试均先验证旧行为失败，再验证修复后通过。后端使用临时数据和模拟上游；浏览器使用独立配置及模拟服务，不调用付费生成接口。

后端复测：在副本根目录运行 `python -B app/tests/run-phase1-backend.py`。该脚本创建独立测试目录，并限制本进程网络连接为 loopback。

浏览器复测需安装 Playwright，并设置 `PLAYWRIGHT_MODULE`、`CHROMIUM_EXECUTABLE`、`PYTHON_EXECUTABLE`；运行 `node app/tests/check-phase1-interactions.cjs` 和 `node app/tests/check-phase1-save.cjs --browser`。已有画布回归的五个入口也支持 `PYTHON_EXECUTABLE`，不要求把运行时复制进 app/python。

## 数据兼容、备份与恢复

- 本次未读取或迁移用户的真实项目和凭证；全部操作发生在独立副本与测试目录。
- 原始审查副本保持不变。根目录 SOURCE_EXPORT.json 仍描述原始基线，不能当作修复后文件校验清单。
- 项目索引备份为运行数据目录内的 `data/projects.json.bak`，仅包含项目索引，不包含画布和媒体备份。
- 首页索引损坏提示中的恢复操作调用 `POST /api/projects/recovery/restore`；恢复前保留 `projects.json.corrupt-<uuid>`。健康索引拒绝覆盖成旧备份。
- 恢复后需要核对最近新增或改名的项目；多个画布迁移失败保留已完成部分，支持再次操作，不自动反向覆盖。
- 未验证真实断电、跨进程竞争、所有供应商调用、低配长时间运行和正式安装更新；现有 ModelScope 专用完整 Token 接口保留兼容，尚未迁移为纯后端代调用。
