# 0.10.2-studio.13 公共画廊网站入口

日期：2026-10-18。基于 `6dec171`，仅修改 344996 的开发副本。原来源仓库与只读评估副本未改动。

## 改动

工作台导航和两种画布的“更多工具”增加“公共画廊”。弹窗配置网站根地址，保存后明确点击链接打开新页。地址仅接受 HTTPS 或本机调试 HTTP，拒绝 URL 凭据、查询参数和路径；本地配置使用原子写入，保存失败不覆盖前值。

用户未确定域名，所以默认不填写虚构地址。可以先填本机独立画廊地址进行测试，部署后改为正式 HTTPS 网站。公共网站独立在 `344996/deepwhite-gallery` 开发；本站登录使用用户指定的 `https://api.deepwhiteai.com` 账号站，真实账号兼容性仍待联调。

网站 0.1.0 提供主动上传、私有草稿、审核与退回、公开展示、搜索、分享、撤回和删除。本地画布保留免登录编辑及自选 API；入口不自动传递账号、密钥、完整画布或素材。

## 验证与未完成

本轮完整结果见[画廊接入与测试](../../../docs/公共画廊接入与测试.md)。网站使用真实本地服务器/数据库和模拟账号站，未发送真实邮件或调用付费生成。

尚未完成公网部署、真实账号联调、微信、独立自动更新、通用 MCP 扩展、大流量运营和完整 Windows 安装发行。全部既有能力与缺口见[累计功能状态](0.10.2-studio.13-status.md)。

## 兼容、数据与回退

画布 JSON、节点协议和项目数据 schema 没有变化；仅运行数据目录增加 `data/studio_gallery.json`，只含网址。原项目索引备份和草稿机制继续生效，不表示所有素材已被完整备份。

需要回退时可检出上版 `6dec171` 并继续使用原画布数据；旧版忽略新网址配置。网站数据在独立服务中，回退画布不会删除网站作品。网站数据库和媒体需单独备份；本版不提供自动更新或降级迁移。
