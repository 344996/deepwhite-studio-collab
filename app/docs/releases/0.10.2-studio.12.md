# 0.10.2-studio.12 工作台与画布体验更新

日期：2026-10-18。开发仓库：[344996/deepwhite-studio-collab](https://github.com/344996/deepwhite-studio-collab)。本版以第一批修复提交 `9e84b6a` 为基础，原始来源仓库未修改。

## 本次行为变化

工作台增加固定导航、明确的新建区域和经典/智能画布快捷入口；项目画布、本地资产和 API 设置直接可达。布局参考用户提供的 LibTV 首页结构，保留深白片场品牌和已有业务操作，没有移植广告、在线社区或未实现的模型入口。

两种画布保留原引擎，搜索、API 设置和账号入口保持可见，辅助工具收进“更多工具”。保留旧 DOM 事件与工具挂载容器。窄屏调整顶部/底部操作区，工作台侧栏可以展开关闭；动效仅用于按钮和弹层反馈，减少动态效果偏好会关闭这些动画，不给节点和世界坐标添加拖尾动画。

智能画布补上已有的登录注册模块。三页使用同一 API 网站账号桥接；登录表单立即显示，不再等待配置渠道余额。登录与模型 API 配置仍分离，未登录可以创建和编辑本地画布。API 站沿用 `https://api.deepwhiteai.com`。

补充基础 `requirements.txt` 和源码启动步骤；保留原打包启动器，不包含 Python/GPU 模型的完整安装包。新增 AI 开发指南和四项扩展方案，按原文档先评估微信、画廊、在线更新与 MCP 扩展。

## 累计功能

全部既有能力和缺口见[累计状态](0.10.2-studio.12-status.md)，包括第一批安全、保存与恢复、经典/智能节点、资产、账号、自选 API、已有生成适配、工作流、任务回执、草稿和 MCP 基础。本版不把已有的部分实现升级描述为全部真实服务验收通过。

## 验证

实际结果与可运行入口见[本轮测试报告](../../../docs/本轮修改与测试.md)。测试使用独立数据和模拟服务；前端没有发起真实付费生成，注册测试没有实际发送邮件。

## 数据和恢复边界

没有修改用户真实项目、密钥或运行目录。第一批项目索引备份与损坏原件保留机制继续生效；上一版索引不等于最新项目和媒体的完整备份。新布局不改变画布 JSON schema。

源码启动默认创建本副本的 `app/workspace`，用户可以通过 `DEEPWHITE_STUDIO_RUNTIME_DIR` 指定独立目录。原 `.cmd` 入口仍用于带 `app/python` 的完整打包目录；源码启动请看[AI 开发指南](../../../docs/AI开发指南.md)。更新失败回退、正式安装升级和真实供应商联调仍需后续验收。
