# 0.10.2-studio.4 · 媒体交互与画布性能

日期：2026-10-03。延续用户已确认的 Studio V2 方向。本次继续接入媒体主题，修复实际删除与截帧操作，并降低经典大画布的重复扫描。源码已更新，本次未重启真实服务。完整能力及未完成项见[累计状态](0.10.2-studio.4-status.md)。

继承[上一版](0.10.2-studio.3.md)的撤销任务保护、专业工具、未保存浏览器草稿和本地账本；迁入来源及原始验证基线见 [0929.1](0.10.1-0929.1.md)。旧版本测试不计入本轮结果。

## 可见变化与修复

经典及智能画布的图片、视频、音频、空素材、结果缩略图、播放与删除按钮跟随共享主题。透明图片保留原像素，原图和视频不加滤镜、不改变原有适配方式；音频播放器跟随深浅主题。键盘聚焦时显示原先只在悬停时出现的删除操作，危险操作保留文字/图标和焦点反馈。

经典画布删除单张结果前记录编辑历史，Ctrl+Z 可恢复原集合，保存重开继续保留。仅对实际存在的结果记录撤销；进行中占位任务的删除行为保持原逻辑。

经典视频“截取当前帧”改为播放器内的浮动按钮，不再作为横排内容挤窄视频或把文字挤成竖排。原有批量“截取关键帧”入口保留，两者功能不同。结果视频缩略图内三个操作分开排列，避免批量截帧遮住播放按钮；仅调整内部定位，节点外部尺寸不变。截帧仍解码本地视频、保留原分辨率及来源时间，并创建独立图片节点。

修复同页异步切换时的模型菜单归属：切换 B 的请求等待期间，在 A 打开的菜单曾会按相同节点 ID 重新绑定到 B，选择后误改并保存 B 的模型。现在菜单绑定原画布和节点对象；删除、远端替换或切换后失效关闭，选择前再次校验。正常保存及同一节点仅重建 DOM 时仍可继续选择，并将展开状态及选择后、Escape 后的焦点移回新的控件。智能画布也核对当前编辑节点，旧选项不能改变新节点或渠道默认值；菜单关闭后释放旧选项持有的引用。

## 性能实现

小地图直接使用 ResizeObserver 已提供的尺寸，位置和选中变化只读取节点数据。内容展开、图片延迟加载和窗口变化仍更新尺寸；同 ID 节点替换与跨画布切换会正确重建观察和缓存。地图绘制不再同步查询节点和容器的几何尺寸。

经典画布的模型控件只装饰实际受影响的节点，使用节点 ID 索引查询数据。引用缩略图和其他无关内容变化不触发全图模型扫描；渠道、目录和模型变化保留完整更新。智能画布继续保留其原有观察范围，并使用同样的索引查找。

经典页面只加载预编译的 Tailwind 样式，移除会在节点变化时扫描全页面的运行时编译器。沿用原固定 3.4.17 编译器、基础重置和工具类顺序；构建输入与输出散列随源码提交。操作及来源见[静态样式构建](../../../docs/画布静态样式构建.md)。

## 同轮性能对照

环境：Windows、i5-14600KF、32 GiB、Edge 154 无界面浏览器，本地素材及 100/300 混合节点。基线为本轮改动前 `4cfdee0` 的重新采样；最终采样时没有其他验收浏览器并行运行。报告保存在系统临时目录 `deepwhite-canvas-edit-performance-review` 与 `deepwhite-canvas-performance-review`，标签分别为 `round2-baseline` / `round2-final`。以下均是同轮数据，不混用上版历史峰值。

| 测量项目（300 节点） | 改动前 | 本版实测 |
|---|---:|---:|
| 整段替换文字：最长主线程任务 | 220 ms | 74 ms |
| 分段真实输入：最长主线程任务 | 77 ms | 68 ms |
| 整段替换：小地图单次最长处理 | 160.3 ms | 0.9 ms |
| 平移/滚轮缩放：最长主线程任务 | 239 ms | 214 ms |
| 平移/滚轮缩放：小地图处理累计 | 352.9 ms | 1.4 ms |
| 框选及选中节点拖动：最长主线程任务 | 460 ms | 247 ms |
| 框选及拖动：长任务累计 | 2680 ms | 824 ms |
| 同页面切回 300 节点画布（三次） | 4.25–4.36 s | 3.40–3.52 s |

100 节点两种编辑采样均没有超过 50ms 的长任务。300 节点整段替换/分段输入的阶段时间分别为 906/1246ms；含驱动、等待和保存采样，不能解读为每次键盘延迟或每帧耗时。

CPU 采样已不再出现 Tailwind 全页面扫描及模型全图装饰热点；文本编辑仍有约 48ms 布局和约 33ms 原生引用更新，平移与拖动仍存在明显长任务。小地图成本下降不等于整体已达到 60fps。三次切回的 live DOM 23356、事件监听 24370 保持稳定，window/document/board 监听为 68/33/15；短时计数稳定不能证明长期零泄漏。
