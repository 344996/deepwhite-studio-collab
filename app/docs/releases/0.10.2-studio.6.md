# 0.10.2-studio.6 · 导航连线与编辑生命周期

- 日期：2026-10-03。
- 类型：正式画布源码改进；本轮未重启真实服务。
- 基于版本：[0.10.2-studio.5](0.10.2-studio.5.md)，提交 `97288a4`。原迁入与需求基线见 [0929.1](0.10.1-0929.1.md)。
- 范围：经典画布视口连线、定位动画与手势衔接，智能提示词原生撤销及持续输入诊断。

## 本次新增与修复

沿用已确认的 Demo 方向和深灰绿、暖金、米白配色，继续完善正式画布。纯视口缩放、定位和平移复用现有连线 SVG，流动动画不会因每帧重建而从头开始。节点几何改变时照常更新连线；同一次绘制共用节点和端口测量结果，测量值不会保留到下一帧或另一个画布。

经典画布定位动画在用户按下输入框、节点、尺寸手柄、端口或导航图时停止，让用户接手操作。中断位置按原有浏览器会话机制保存；修复 6% 缩放重新打开被限制为 12% 的不一致。保存范围不是跨设备同步。

智能画布重绘时让提示词编辑框保持原 DOM 位置。此前点击保存或菜单使输入框失焦后，同父容器内重新挂载会清掉 Chromium 原生撤销历史；现在同父时不重挂，不清空用户历史来减少保留对象。不同节点仍分别保存和加载各自草稿。操作说明见[画布缩放与编辑](../../../docs/画布缩放与编辑.md)。

## 性能证据

本轮基线重新从 `97288a4` 采集，Windows / Edge 154.0.4258.53，300 节点、150 连线。修改前后使用相同动作和数据，均独占测试浏览器。两轮四种操作都没有 ≥50ms 长任务，不能用上一版的 111ms 滚轮峰值冒充本轮基线。

| 操作 | renderLinks 次数（前 → 后） | 连线绘制合计耗时 | 单次绘制最长 |
|---|---:|---:|---:|
| 平移 | 0 → 0 | 0 → 0ms | 0 → 0ms |
| 8 次滚轮缩放 | 8 → 0 | 70.5 → 0ms | 9.1 → 0ms |
| 框选 | 1 → 1 | 7.8 → 2.2ms | 7.8 → 2.2ms |
| 拖动节点 | 21 → 21 | 180.1 → 52.6ms | 8.9 → 4.0ms |

拖动期间连线绘制合计减少约 70.8%；实际需要改变几何的绘制次数仍为 21。滚轮没有重建 SVG，但仍有其他画布工作，不能理解成零开销。六档缩放下原连线世界坐标误差不超过 0.000424，SVG 与节点仍在同一世界容器中。

空白区域悬停仍逐条计算连接距离。最终空间检查中，41 次鼠标移动累计该部分约 245.4ms，单次峰值 6.8ms；本轮未优化此路径，保留为后续性能工作。

原始四阶段 trace、CPU 采样及对比文件位于系统临时目录 `deepwhite-classic-links-baseline` 和 `deepwhite-classic-links-final`。数值为本机单次采样，不是低配、长时间稳定或全程 60fps 的承诺。

## 编辑生命周期诊断

[诊断脚本](../../tests/check-smart-editor-retention.cjs)按组记录 GC 后对象、页面实际元素、监听器与堆引用路径；这是原因分析，不是“零泄漏”门禁。以下均为本轮在修复前 `97288a4` 上完成的 300 轮对照，Chromium 152.0.7977.8：

| 对照路径 | 保留 DOM 对象（预热后 → 300 轮） | 保留监听器 |
|---|---:|---:|
| 空白 contenteditable，实际填充 | 24 → 624 | 13 → 13 |
| 空白 contenteditable，原始 CDP 输入 | 22 → 622 | 0 → 0 |
| 空白 contenteditable，程序设置 textContent | 8 → 8 | 26 → 26 |
| Smart 只连续填充提示词 | 2374 → 2375 | 460 → 460 |
| Smart 搜索填充、选择、模型菜单及重绘 | 2377 → 2678 | 460 → 460 |
| Smart 同时编辑提示词并保存 | 2396 → 2697 | 460 → 460 |
| Smart 相同界面循环、不改搜索输入 | 2373 → 2373 | 461 → 461 |

释放 CDP 会话后文本对象仍保留。强引用路径经过 `WebLocalFrameImpl → LocalFrame → Editor → UndoStack → UndoStep → Text`；原始 CDP 输入对照也增长，不能把它简单归因于 Playwright 句柄。Smart 路径中搜索词的原生撤销历史解释了对应文本保留；不改搜索输入的对照没有对应 DOM 增长，但 JS 堆仍增加，包含编译代码。此证据不证明所有界面都无泄漏，也不代表数小时稳定。

诊断还发现保存后撤销失效的独立功能缺陷：真实点击回输入框后焦点与光标均正确，快捷键没有被阻止；只在隔离页面跳过同父重挂即可恢复撤销。这一临时因果实验不计作正式修复后的回归通过。修复后的硬断言入口为 [check-smart-editor-undo.cjs](../../tests/check-smart-editor-undo.cjs)，禁止启用临时替换。

修复后的同条件两个 300 轮对照已完成：

| 修复后路径 | 保留 DOM 对象 | 页面实际元素 / 保留监听器 | JS 堆字节 |
|---|---:|---|---:|
| 搜索、菜单、提示词编辑、保存及重绘 | 2420 → 3621 | 1158 / 460，均不变 | 5,501,588 → 6,313,292 |
| 相同界面循环、不改搜索输入 | 2373 → 2373 | 1161 / 461，均不变 | 5,391,840 → 6,134,544 |

第一组比修复前保留更多文本对象：净增 Text 901、br 300、UndoStep 601，释放 CDP 会话后仍保留，抽样强引用路径落在 Blink UndoStack。修复保住了真实可用的撤销记录，因此不能把修复前较小增长当成当前版本指标；本版没有清历史压低内存数值。没有搜索输入的对照仍无对应 DOM 增长，但堆并非不增长。两个诊断中的页面异常、外部及生成请求均为 0；诊断不是全部场景或长期零泄漏保证。

修复前报告保留在系统临时目录 `deepwhite-smart-editor-retention`；修复后报告、堆快照与独立硬回归位于 `deepwhite-smart-editor-retention-post-fix`，没有覆盖前报告。

## 尚未实现与下一步

节点内普通文本仍随世界坐标缩放；固定屏幕尺寸适用于智能选中编辑卡和工具条。本机两窗口与限定轮次检查不代表所有输入法、低配设备、数小时或多窗口真实任务压力。

原生视频/文本、MJ、ModelScope 专用端点及直接 RH/MiniMax 的可靠性缺口继续按[原生入口审查](../../../docs/原生生成入口可靠性审查.md)推进。真实收费输出、GPU、真实邮箱、生产回退及 Windows 完整桌面发行仍待验收。RH 闭源参考库按用户决定暂缓，不恢复已撤回的在线画廊。
