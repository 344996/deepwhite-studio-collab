# 0.9.0-feedback.1 · 0926 反馈改进

## 本次改进

围绕 0926 用户测试反馈调整普通画布。模型菜单先选择系列、版本，再选择可用通道；本地 ComfyUI 单列。图片张数移到外部操作行。账户区展示 API 返回的头像，未提供时显示首字头像；钱包以独立余额卡展示，保留刷新和退出。

设置页增加 API、即梦账号、本地 ComfyUI 的连接入口。原智能画布从新建菜单隐藏，已有智能画布继续保留访问。原白/黑主题与附加主题继续保留。

左侧改为处理工具栏，双图对比在独立面板操作，不再创建节点；视频截帧、图片处理、分组和可选连线方向动画集中于此。右上保留账户、设置、助手和引擎状态。双击空白处仍负责创建节点。

TXT 拖入后成为可编辑文本节点，标题使用文件名。图片卡片依据原图比例调整高度；连线端点按真实节点边缘计算。修复主题往返时残留的附加主题颜色。

上传剧本会建立可编辑源文本节点；确认助手方案后建立 Skill 节点和对应图片/视频节点，以虚线展示处理关系。Skill 节点可返回原会话继续修改；同一会话中相同稳定编号的输出复用已有节点，并保留生成结果。视频素材仍使用真实参考连接和 @ 映射。助手高级模型选项默认折叠，纯文字答复会明确说明未创建节点。

Skill 节点是现有助手会话的可见记录和继续操作入口，尚不是可独立排队执行的通用工作流引擎。首次确认方案后才创建 Skill 节点；创建节点不会自动发起媒体生成。

目录选择器增加前置窗口和超时处理，取消时恢复原路径；选中后直接保存，已有素材先确认再复制校验并切换引用，原文件保留。即梦账号提供退出、重新授权/换号、取消授权，区分停用通道与退出账号，并阻止未完成或状态不明确任务期间切换账号。

## 本地 ComfyUI

已适配的 Qwen Image 2.1 单图编辑工作流增加主模型和 CFG 参数。读取引擎 UNETLoader 列表，仅筛选 Qwen Image 2.1 命名的 safetensors；不代表任意架构或自定义量化格式均兼容，提交时仍核对实际节点参数。当前本机只读查询到一个匹配主模型，因此不能宣称已完成多种主模型的真实 GPU 验收。

引擎未检测或离线时，模型选择显示待检测并禁用，不把固定默认文件名当作已安装证明。引擎在线但没有兼容型号时显示缺少模型，实际提交前再次核对。

节点新增运行进度条。引擎返回采样进度时显示当前阶段百分比；没有数值时显示不定进度及阶段，不推算虚假的整任务百分比。WebSocket 断开不会重发生成任务，最终结果仍以任务记录为准。

## 同步修复

修复浏览器读取已保存生成记录时不必要地标记本地编辑的问题。MCP 生成由服务端回写，浏览器只展示，避免两端争抢写入引发草稿冲突；用户真正的未保存编辑仍受原冲突保护。

- 按[20 项复测清单](../0926改进版复测清单.md)验收本次变化；完整历史能力仍参考[累计状态](0.9.0-feedback.1-status.md)。
- 后端检查覆盖生成适配、ComfyUI 参数与模型检测、阶段进度、目录迁移、账号授权状态、资产、Agent 方案、MCP 与画布版本冲突。
- 本轮累计 115 项 Python 检查通过：生成 17、本地工作流 10、模型检测 4、进度/头像 2、账户价格 9、存储 7、即梦 17、Agent 12、控制输入 4、控制器 11、MCP 6、画布并发 2、资产及集成 12、通道存储集成 2。
- 浏览器回归覆盖四主题往返、左右工具栏、连线吸附、TXT 导入与持久化、图片比例、双图对比、真实 WebM 截帧、模型/通道菜单、外部张数、账户卡与连接设置。
- 目录取消/选中即保存/迁移确认，以及即梦取消/退出/再次授权均使用模拟接口验收；未实际移动用户生产素材或退出用户账号。
- 实际 stdio MCP 到控制器、浏览器确认、模拟图片/视频生成和结果回写通过；未保存草稿在外部更新时保持冲突保护。
- Agent 浏览器闭环通过：上传剧本、文本源节点、确认方案、Skill/输出节点、撤销、第二轮图片视觉输入、视频素材映射及刷新恢复。模型答复使用模拟接口；4 次模拟模型调用不代表真实创作质量验收。
- 最终截图复核修正 Skill 虚线层级与对比度；0.4 倍缩放下关系线可见，“继续对话”可实际点击并打开原会话。
- 没有发起真实收费生成、真实登录/退出或本机 GPU 任务。原生文件夹窗口在用户桌面的前置效果、真实账号和实际模型输出仍需要复测。
- 正式服务已重启并核验版本为 `0.9.0-feedback.1`，首页、设置、画布与新增资源返回正常。本机只读检测到 1 个兼容 Qwen 主模型；生成记录仍为原有 8 个成功、2 个失败，本轮未新增生产生成任务。
