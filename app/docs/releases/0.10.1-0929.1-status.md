## 本版覆盖

- 画布：保留原主题、渠道优先、网格/吸附/分组/撤销、特殊对比节点；图片与视频统一上游顺序加手写提示词；真实播放器当前帧保存，隐藏图片处理入口而保留数据。
- 内容：首页项目文件夹/画布管理、搜索、列表与网格；Fisher 固定公开提交 727 条条目、1220 个素材，风格/滤镜按源定义作为生成预设，MJ 参数仅用于兼容模型。
- 音频、账户、ComfyUI 和通用 RH：见下表及本版使用说明。
- RH 闭源参考库：用户确认无法直接看到时先跳过，未宣称导入完整参考库。既有配置和用户自添链接可继续使用。

## 三、Agent 既有边界

- 单 Agent 工具循环，每轮最多 4 次模型调用，不是产品内多 Agent 团队。
- Skill 节点在首次确认方案后建立，用于显示处理关系、状态并继续原会话；不是独立排队或自动执行媒体生成的工作流引擎。
- 对话产生模型费用；确认写入仅创建/更新节点，不自动批量生成媒体。
- 长期语义记忆、PDF/OCR、大剧本自动分批、后台长流程恢复与自动预算执行未实现。
- 技能限文本与引用规则；基础模板不能代表用户完整专业经验已经移植。
- 方案检查资产版本、项目归属和画布修订；画布变化会拒绝旧方案覆盖。
