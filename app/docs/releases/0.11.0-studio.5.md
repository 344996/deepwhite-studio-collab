# 0.11.0-studio.5 · 客户安装与 Codex 自动配置

- 日期：2026-10-21。
- 基于：0.11.0-studio.4；独立画廊仍为 0.4.0 / schema 4。
- 类型：正式接入功能；交付源码、完整 Windows 便携包及本机预览。

## 本次新增与修复

外接智能体设置改为启用访问、自动配置 Codex、检查连接三个步骤。原始路径、TOML/JSON 和排错命令收进高级选项。客户使用自己的安装位置和当前 Windows 用户目录，不用照抄开发者配置。

新增 Codex 配置安装/更新、显式冲突确认、备份及撤销。保留其他模型、服务、注释和工具审批策略；重复安装不重复写入。配置损坏、并发修改、不可写或异常链接位置会停止修改并给出提示。便携包沿用固定启动入口，升级后选择当前版本；移动目录后从新位置重新自动配置。

本版完整包同时包含 .2 生成记录、.3 界面、.4 按钮和图片反馈的改动，修正此前只有源码与预览更新、便携包停留在 .1 的交付缺口。

## 当前版本累计功能

见 [本版完整累计状态](0.11.0-studio.5-status.md)。原来的画布编辑、保存、API 与画廊能力保留；微信继续暂缓。自动配置 Codex 不改变生成授权，不增加可收费调用，也不代表任意客户端均已适配。

## 使用与验证

完整解压 `windows-x64-portable.zip` 后双击 `Start.cmd`，打开设置里的外接智能体，启用 MCP 并自动配置 Codex；检查本机连接后重启 Codex 的 MCP 连接，使用页面的测试指令验证读取。

[客户操作与维护说明](../../../docs/客户安装与Codex连接.md) · [本次发行与实际验收](../../../docs/发行产物-20261021.md)。

新回归使用隔离配置目录、合成项目及实际解压包；不修改维护者的真实 Codex 配置，不调用收费生成服务。源码测试、实际 ZIP 验收和真实 Codex 客户端联调分开记录。

## 数据兼容、备份与恢复

无画布 schema 迁移，继续使用独立 `userdata/`。自动配置的原文件备份保存在客户自己的 Codex 目录，并支持仅撤销上次深白连接变更。原来无配置文件时撤销留下空文件。用户自选外部素材仍需另外备份。

所有源码变更在 `344996` 开发副本，保留提交历史，原作者仓库不变。

## 尚未实现与限制

Windows 原生 Codex 是自动配置目标；WSL、容器、远程 Codex、企业策略或项目/profile 覆盖不自动修改。Claude/通用 JSON 保留手动入口。真实客户物理电脑的系统策略、真实收费生成、GPU、生产画廊与长期大画布性能仍待验收；本机隔离测试不代替这些结果。

本版先交付本地完整包；公开 Release 和在线更新源的实际状态以本次发行记录为准，不能用源码提交替代发布。
