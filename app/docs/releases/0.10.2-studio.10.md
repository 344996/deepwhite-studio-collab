## 本次新增与修复

两种画布的工具栏新增「工作流工作台」。来源列表、搜索、导入预览、参数编辑、实时节点预览、草稿与版本保存在统一窗口中完成，配色使用现有共享主题变量。ComfyUI 与 RH 各自读取正式本地接口；一个来源失败不会把另一来源隐藏，也不会将失败伪装为空库。连接与参数读取以实际接口响应为准。

ComfyUI 支持 API JSON 和可转换的普通工作流 JSON。预览检查节点、模型枚举及连线，不创建库记录或生成任务；显式保存后才产生版本并允许添加画布节点。参数可改标签、类型、默认值、顺序、暴露开关与输出选择；修改旧配置会保留 required/min/max/step 约束，旧节点保持原版本。仍只预置 Qwen Image 2.1，不安装节点或下载模型。

自定义 ComfyUI 整数、种子与范围用十进制字符串跨越浏览器，后台按引擎实际整数定义恢复精确值。0、false、数值/文本枚举保持语义，歧义选项明确拒绝。旧数据已经舍入的值无法恢复；原生 legacy ComfyUI 字段精度不在本次修改范围。并发保存同一版本时只有一次成功，其余显示冲突；损坏记录明确报错且保留原文件。

RH 可从应用/工作流链接、ID、JSON 或既有配置导入预览，显式保存到独立本地版本库；不覆盖整份渠道设置。同名配置独立，保留参数、精确种子、0/false、范围、图片顺序与完整工作流图。经典画布新节点固定选定版本，沿用既有素材上传、保存屏障与持久任务链；工作流提交携带固定图，保留可选图片裁剪规则。RH 应用只能固定应用 ID、参数结构及本地输入，不能冻结平台内部实现。RH 任务输出由远端响应决定，不能冒充已知的 ComfyUI 输出端口。

两种画布均可管理和预览工作流；本版新增 RH/自定义 ComfyUI 节点限定经典画布。智能画布缺少对应原生创建能力时明确提示切换经典画布，不创建假节点。既有智能画布、Qwen 和旧工作流入口保留原能力。

自定义 ComfyUI 提交先保存并回读固定请求、节点与输出目标；未保存或切换对象时不派发。回执丢失按原请求编号读取本地账本，找不到仍待核实，不自动重新生成。查询仅跟踪原任务；历史恢复的节点须显式核实，旧格式仅有任务 ID 的节点仍可查询。输出删除或重连后，晚结果保留任务链接，不写入新输出节点。后台任务状态查询与归档可能访问原服务；只有能力探测、按请求编号查账本是纯本地读取。

复制节点保留配置、版本与参数，清除任务身份；撤销恢复保留原回执并暂停续查；浏览器编辑草稿不会覆盖服务器新回执。工作台标签页草稿提供保留、放弃、取消与导出，不能代替项目和素材备份。

## 数据兼容、备份与恢复

新增字段默认兼容旧节点，不覆盖原程序目录或迁移用户项目。已有任务使用原记录的服务地址与回执；未知结果不通过重提恢复。RH 新配置版本与旧渠道配置独立，旧项仅在显式保存后进入新库。ComfyUI 并发版本保护适用于当前单进程服务，不宣称多进程协调；RH 版本库使用本机文件锁。

本轮未读取或备份生产数据，未重启真实服务。源码版本不等于当前运行版本；正式窗口须在后续启动后核验。Git 回滚只覆盖源码，不恢复用户数据；回退时保留工作流版本、素材和任务账本。工作台草稿仅用于标签页编辑恢复。
