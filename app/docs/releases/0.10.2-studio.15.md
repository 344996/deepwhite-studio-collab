# 0.10.2-studio.15 · 画廊提示词创作

- 日期：2026-10-19
- 类型：正式功能源码，本地验收；尚未上线公网
- 基于版本：0.10.2-studio.14
- 本次范围：画廊提示词预览与导入，对接独立画廊 0.2.0，提供修改指南

## 本次新增与修复

新增 `/gallery-import` 页面，支持画廊链接或用户选择 JSON 文件。展示来源、标题与提示词，用户确认后在所选项目创建普通画布和文字节点，随后可按原有方式连接模型节点。

新增 `/api/studio/gallery/import`，校验同源 Origin、版本化白名单和实际接收字节数。画布原子保存；持久收据保证原请求重试不重复创建、不覆盖后续编辑，也不会自动复活已删除画布。保存错误保留前端请求，刷新同一标签页仍可重试。

工作台、经典与智能画布的公共画廊弹窗新增“导入提示词文件”入口，在新标签打开，不离开正在编辑的画布。本次导入只创建普通文字节点，不读取远程媒体，不传递账号或生成密钥，不自动生成或扣费。

独立网站 0.2.0 新增纯提示词作品、搜索与配额、复制/导出和跳转创作入口；媒体作品仍按需公开提示词。具体改哪个文件和怎样继续做站内生成，见[画廊修改指南](https://github.com/344996/deepwhite-gallery/blob/main/docs/画廊基础架构与修改指南.md)。

## 使用与验证

最短路径：画廊作品 → 使用此提示词创作 → 带到本地画布 → 确认创建 → 在画布连接生成节点并选择 API。备用：导出文件 → 本地公共画廊弹窗 → 导入提示词文件。API 网站按钮只打开首页，提示词自行复制粘贴。

本轮实际结果：后端 309 项通过（含新增导入 8 项）；工作台 37 组、核心交互 17 组、保存 8 组、MCP stdio/浏览器 6 组通过。网站后端 36 项、网站浏览器 12 组、新提示词双服务 8 组、原入口 1 组通过。依赖一致性与 `pip check` 通过，24 个画布锁定运行依赖、18 个网站实际安装依赖审计均无已知漏洞记录。详见[报告](../../../docs/画廊提示词创作与测试.md)。

均为临时目录和模拟账号/供应商。未使用真实用户账号或付费生成，没有真实 GPU、邮箱、公网 HTTPS/TLS、容器运行、生产压力或完整恢复演练。独立代码审查提出的表单重试问题已修复并通过浏览器回归。

## 数据兼容、备份与恢复

- 原画布格式不变；新增可选来源和导入记录字段。旧画布继续可读，不迁移真实数据。
- 新收据在运行数据目录 `studio_gallery_imports/`，须随画布、项目索引、资产与任务数据一起备份；前端未完成导入状态只在当前标签页 sessionStorage，不等同于长期备份。
- 本轮只写测试临时目录，Git 保留源码版本；未为真实运行数据执行备份或恢复。升级前先停止服务，备份完整运行目录和必要配置；不要把 Git 当作素材与密钥备份。
- 回退至 .14 后已导入文字节点仍可读，导入页/API 消失；不要删除导入收据。网站 0.2.0 的纯文字作品不兼容 0.1.0 的媒体假设，网站代码回退必须配套数据恢复，恢复前另存现有数据。
- 结果不确定时先核对工作台，用原请求重试；已永久删除的画布须以新的明确导入操作重新创建。
