# 0.7.0-channels-storage.1 · 可选即梦通道与本地项目存储

日期：2026-09-25。基于 0.6.0-agent.1。累计功能与未完成项见[完整功能状态](0.7.0-channels-storage.1-status.md)。

## 本次交付

### 可选即梦账号通道

在「设置 / API → 第三方平台 · 即梦」填写或检查本机 Dreamina CLI 程序位置，启用通道并点击授权登录。打开即梦官方授权页面完成操作后，界面检查并显示连接结果。不会自动登录、购买会员或提交测试生成。

即梦模型加入普通画布原有图片、视频节点的模型选择区域，保留“系列 → 版本”两级选择；调用来源明确标为即梦账号。型号及参数来自已核对的 CLI 命令帮助和产品适配目录，不宣称从个人账号拉取到了所有模型权限。用户可停用不需要的模型。

授权状态独立保存在 DeepWhite 工作区；通道默认关闭，不替换默认 DeepWhite API，不改其他程序的即梦登录。关闭通道后旧节点保留原选择，生成需要重新启用/连接，不自动切换到其他付费通道。

生成走同一任务和资产系统：提交后保存任务编号、查询进度、下载结果、登记本地资产。即梦显示积分结算提示，不冒用 DeepWhite 的人民币估价；没有可信积分余额时显示未取得余额。单次生成仍须由用户点击。

原版智能画布未接入此通道，其即梦入口不开放。

本版使用用户已安装的 CLI，未制作一键下载安装及更新器。平台会员权限、模型首次使用确认、线上排队和实际积分消耗，以平台响应为准。**小云雀、LibTV 等其他第三方账号通道未实现**；也未在本轮另加火山引擎官方 API 通道。

### 可选择本地项目保存位置

入口为「设置 / API → 基础设置 → 本地项目存储」，以及「项目资产 → 项目保存位置」。

- 全局默认位置用于新项目；已有项目不会随全局设置自动搬迁。
- 每个项目可选择独立目录，也可手工填写本机绝对路径。
- 既有素材迁移采用复制、内容校验、切换索引；原文件保留。失败时不要求重新生成付费内容。
- 图片、视频、音频按受管目录保存，区分导入、候选和正式资产。固定资产版本引用保持不变。
- API、MJ、ComfyUI 和新增即梦生成结果共用资产保存入口；生成信息随受管资产记录，不向媒体目录复制 API 密钥。
- 暂存目录保留在高级设置。远端结果先进入本地暂存，再登记到项目目录；项目位置不可写时保留已知任务及可恢复结果。

这不是任意文件夹双向同步。用户手工在资源管理器移动或删除文件后，本版不会自动重建全部引用。只选择媒体目录也不等于迁移整个软件：画布、会话、资产数据库等仍在软件工作区，完整备份需同时保存工作区与外部项目目录。

## 验证记录

本版使用独立临时工作区、模拟平台响应及测试媒体验证；未启动真实授权登录、付费生图/视频或本地 GPU 任务。

- 74 项 Python 检查通过：存储 6、资产 9、基础生成 17、本地 ComfyUI 7、账号/价格 9、跨模块存储与 Agent 2、资产集成 3、Agent 方案 5、Agent 会话 5、即梦适配 11。测试包含保存失败续查不重提、未知提交结果不自动重试、账户绑定、冲突任务回执拦截、素材模式与数量限制、迁移失败恢复和稳定文件链接。
- 浏览器检查通过：保存默认目录、迁移项目素材、迁移前后同一链接的文件内容一致、刷新恢复设置、资产页入口；即梦设置页、状态、启用模型和模拟授权流程。没有页面脚本错误，第三方请求使用测试响应。
- 普通画布浏览器检查通过：图片与视频点击生成走统一任务接口，携带画布/节点编号、型号、提示词和素材引用；视频保留原始 @素材标记交由后端编译，暂停后继续查询不重复提交。全部生成接口使用本地模拟响应。
- Windows 文件夹选择器验证了调用参数与路径传递，未在本轮人工操作真实选择窗口；同时提供手工填写路径。
- 命令参数与本机 CLI 帮助比对。实际平台登录、模型权限、积分扣费及真实输出仍待用户环境验证。

正式本机服务已更新至本版；健康检查、设置页、画布脚本及新增存储/通道接口可访问。可选即梦通道保持关闭，未修改现有项目保存目录。

## 尚未完成及已知边界

- 即梦真实账号登录、会员权限、真实输出质量和计费仍需用户正式环境实测。
- CLI 版本可能改变参数和响应，需要后续维护适配；目录中出现型号不等于账号拥有权限。
- 小云雀及其他第三方平台、本轮未覆盖的官方 API 通道，均未作为已完成能力交付。
- 云同步、跨设备协作、整目录递归导入、外部文件移动监控及自动清理旧副本未实现。
- 新增通道不会将 Agent 自动升级为自动付费执行器，仍然先准备节点，再由用户生成。
- 既有功能其他未完成内容完整保留在本版累计状态表中。
