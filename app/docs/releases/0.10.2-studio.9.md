## 本次新增与修复

普通自有 API 图片节点（含 GPT/G2 模型）和视频节点沿用已有紧凑生成栏，不再因模型名字匹配而留下另一套大参数面板。已有 footer 保持单份，模型选择留在操作栏，原生数量加减控件继续使用；本轮不强制改写用户节点宽度。

原生参数使用同一份 DOM 和已有处理器，收进共享主题弹层，保留中文分辨率、比例、质量与数量说明，自定义尺寸/比例及参考图自适应功能。摘要按当前实际渠道和参数取值，不被已停用增强路径留下的 studioParams 干扰；数量加减及异步媒体尺寸完成后的摘要同步已纳入本轮隔离专项。

参数弹层以单个活动弹层管理窗口/内容尺寸变化，关闭时释放观察器，不以常驻全图扫描更新布局。原生参数补齐限定范围的独立撤销，参考图适配尺寸也可撤销；本次隔离专项已验证。本改动只涉及普通图片/视频的本轮参数处理器，不能推断所有原生模型或渠道切换都可独立撤销。

原生输入同步同时处理参考素材替换和断开；自适应比例、适配尺寸的异步结果绑定原节点、画布与原参数，节点或画布已切换、参数已修改时丢弃过期响应，不把旧尺寸写入当前节点。

.8 已有上游原始文字只读区、独立手写、来源顺序和素材缩略条继续保留。风格加工不伪装上游原文，0929 已取消的常驻最终提示词预览不恢复。本轮不改供应商协议或真实恢复能力，也不代表全部 UI/需求完成。
