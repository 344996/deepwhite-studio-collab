# 0.11.0-studio.3 · 创作工作台视觉统一

- 日期：2026-10-20。
- 基于：0.11.0-studio.2；画廊仍为 0.4.0 / schema 4。
- 类型：正式界面改进，交付源码与本机预览；未生成便携发行包或公开更新。

## 本次新增与修复

参考 LibTV 公开首页的导航和创作层级，重新设计首页主入口、快捷入口、真实项目封面/提示词摘要及网格列表，统一两种画布、节点编辑器、生成记录和设置的配色与主操作。

补菜单与移动导航键盘体验，修复小屏工具遮挡、旧宽度溢出及智能素材按钮位置问题。减少动画设置可用，节点拖动和画布缩放保持即时响应。

详细设计、代码入口、后续修改和验证见 [界面设计与维护指南](../../../docs/界面设计与维护指南.md)。

## 当前版本累计功能

见 [本版完整累计状态](0.11.0-studio.3-status.md)，完整继承 .2 所有已实现能力及待完成项。此次界面更新不改变 MCP、账号/API、公共画廊、更新流程的原交付边界，微信仍暂缓。

## 使用与验证

打开工作台，选择经典或智能画布；画布右上查看任务/生成记录，更多工具中可继续进入原有设置和画廊入口。

新增首页与画布外观专项，配合生成记录、原 1020 界面、项目 CRUD 与 MJ 历史回归。准确数量和结果见 [验证记录](../../../docs/verification-ui-polish-20261020.json)。均为临时本地服务/合成数据，没有付费生成或本地 GPU 任务；不将历史后端测试计作本次重跑。

## 数据兼容、备份与恢复

画布 schema 1，无数据迁移。本机预览重启前备份数据并核对哈希。完整备份需另外包含用户自选的外部素材目录；恢复旧代码前停止服务并另存最新数据。本轮不触碰原作者仓库，不删除既有历史，改动记录于 344996 的仓库。

## 尚未实现

本版未重新打包 Windows ZIP 或公开 Release；源码版本不等于可下载包版本。公网画廊、客户异机 MCP、真实账户/收费模型、长期性能及其他原有缺口继续保留在累计状态中。
