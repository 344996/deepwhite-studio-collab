## 新增与修复

增加项目和节点约束读取、新建普通画布、文字编辑、普通节点移动和文字连线。一次批量操作原子保存，可撤销最新编辑；冲突、活动任务和重复操作有明确保护。创建失败、进程中断、回收或永久删除的重试不重复生成画布。复制画布隔离旧编辑日志，删除文字清理两种分组。

设置页展示 MCP 编辑范围；访问仍默认关闭，生成仍使用原审批。完整调用示例、测试证据、限制和迁移核验见[本轮报告](../../../docs/项目完整迁移与MCP开发.md)。

发布前将 Requests、Pillow、python-multipart、Starlette 升级到安全修复版本，FastAPI 同步到兼容版本，完整锁定基础运行依赖；新环境后端 301 项、浏览器/时序 68 组通过，24 个实际安装依赖审计未发现已知漏洞。旧版源码回退也不应恢复存在已知问题的旧依赖版本。

## 当前累计功能与未完成

[完整累计状态](0.10.2-studio.14-status.md)继承上版所有能力和缺口：第一批安全/保存/核心交互修复、工作台和两种画布布局、账户/自选 API、独立画廊及既有生成链路继续保留。

MCP 已扩展但尚未支持任意节点、智能画布及完整项目管理。公共画廊未公网部署，账号真实联调待完成；独立在线更新、完整 Windows 发行、真实供应商/GPU与长期大画布验收仍未完成。微信暂缓。

## 使用与验证

入口：设置 → 本地智能体（MCP）→ 查看范围、启用并复制连接配置。没有改写用户 Codex 配置。新测试实际启动 stdio 桥接和本机服务器并核对浏览器，模型目录为模拟服务。没有付费生成、邮件和 GPU 请求。检查命令与结果见本轮报告和机器摘要。

## 兼容、备份与恢复

新增画布内编辑日志和运行目录的创建预约记录，节点格式保持兼容；不迁移真实运行数据。备份须同时覆盖运行数据、项目资产和浏览器草稿，代码提交不是作品备份。保留上版 `1887f21` 回退点；降级后新增 MCP 工具不可用。恢复旧数据不得重放旧操作编号，需先检查现有内容。原上游覆盖式在线更新继续禁用。
