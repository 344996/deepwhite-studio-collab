# 0.11.0-studio.6 · 客户正式发行与在线更新

日期：2026-10-21。开发与发布仓库为 `344996/deepwhite-studio-collab`；原作者仓库不变。

## 本次修复

公网实际升级验收发现 .5 启动器在回退后再次安装同版本时会移动自己的 Python 标准库，导致解压失败。本版把版本目录改为只新增；已有目标必须与签名 ZIP 的新鲜解压结果逐文件一致才复用，任何差异会在停止服务前拒绝，原文件保留。不会通过忽略 HTML、放宽签名或预加载某个模块绕过问题。

启动时不再改写安装目录里的 HTML，所有 HTML 页面在 HTTP 响应中取得当前资源版本并正确处理缓存。旧 ComfyUI 工作流上传、配置和删除改为用户覆盖目录；已保留旧版本的 custom/自定义 工作流只读兼容。RunningHub 用户工作流仍保存在原用户数据中，不再同步改写发行包模板。

升级后如启动器仍在运行旧代码，更新页提示“完成更新并重启”，确认保存后通过现有安全退出协议重启。核对 PID、创建时间、解释器、安装根目录和父子关系，不按端口或进程名称强杀。新版启动器生效前禁止再次安装或回退。

## 使用和验证

完整解压 Windows x64 portable 包，双击 Start.cmd；旧便携版在设置中检查、下载、安装更新。如出现“完成更新并重启”按钮，确认保存后点击，等待页面恢复。客户 Codex 自动配置、搬迁修复和前版界面改进全部保留。

[客户下载与公开测试记录](../../../docs/公开发布与在线更新-20261021.md) 单独记录实际发行包、公开 HTTPS、默认 stable、浏览器和真实 Codex 验证；构建时文档是快照，最终公开状态以该记录为准。失败的 .5 记录保留，不以源码测试代替公网验收。

## 兼容、数据和恢复

画布数据 schema 1 不变，安装前备份 userdata；成功后手动回退程序保留最新作品，失败回退在恢复编辑前恢复旧备份。外部素材与浏览器未保存草稿需单独保存。旧式工作流现在写 userdata/data/legacy-workflows；回退到没有此修复的旧程序时，该目录仍保留但旧程序不会读取，回到本版恢复显示。旧版本自定义文件只读兼容，不搬迁或覆盖。

已有同名版本内容被改动时停止自动覆盖；保留完整安装目录，关闭画布后把完整 userdata 备份到另一个安全位置，再用新完整包恢复。不要把整套新包覆盖到旧目录中。已有版本中的旧式自定义工作流还应保留原版本目录或先导出，外部媒体另行备份。
