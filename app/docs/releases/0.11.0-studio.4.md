# 0.11.0-studio.4 · 按钮与图片交互细节

- 日期：2026-10-20。
- 基于：0.11.0-studio.3；画廊仍为 0.4.0 / schema 4。
- 类型：正式界面改进；交付源码和本机预览，未生成新便携包或公开更新。

## 本次新增与修复

首页、两种画布、设置和资产加入统一的轻微悬停提亮、按下收紧与松开回弹。项目封面、素材缩略图和生成记录图片有独立反馈；嵌套菜单不触发整张卡片的按压效果。

生成记录图片可直接点击放大，资产缩略图改成支持键盘的原生按钮。修复画布快捷键抢占按钮空格的问题；原有背景空格平移、节点编辑与保存仍保留。

补动态禁用、滚动/触摸取消和窗口失焦后的状态清理；浅色主题、键盘焦点与减少动画设置均有对应处理。

具体调整入口见 [交互细节与动效维护](../../../docs/交互细节与动效维护.md)。

## 当前版本累计功能

见 [本版完整累计状态](0.11.0-studio.4-status.md)，完整继承 .3 的已实现能力及待完成项。本版不改变 MCP、账号/API、画廊和在线更新的原有交付边界，微信继续暂缓。

## 使用与验证

工作台按钮和项目封面支持悬停、按下、移开取消；画布打开任务记录后直接点击图片放大。Tab 聚焦按钮后，Enter/空格可执行原生操作。

新增交互专项，回归首页、两种画布、生成记录和 1020 的保存、撤销、连线流程。具体执行数量和结果见 [测试记录](../../../docs/verification-interaction-details-20261020.json)。测试使用临时服务、合成项目及媒体；没有真实收费生成或 GPU 任务。

## 数据兼容、备份与恢复

无 schema 迁移。本机预览重启前备份数据目录并对照文件哈希；用户自选的外部素材目录需另外备份。恢复旧代码前停止服务并另存最新数据。所有改动在 `344996` 的开发副本中，保留原有 Git 历史，原作者仓库不变。
