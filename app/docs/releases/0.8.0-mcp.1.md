# 0.8.0-mcp.1 · 深白片场与本地智能体控制

日期：2026-09-25。基于 0.7.0-channels-storage.1。这是正式功能版本；累计能力与未完成项见[完整功能状态](0.8.0-mcp.1-status.md)。

## 本次交付

中文产品名统一为“深白片场”，英文名继续使用 DeepWhite Studio。首页、画布窗口、设置和资产页更新可见名称，新增中文启动/停止入口。项目目录、API 平台名称、资产编号和旧启动入口保持兼容。

新增可选本地 MCP 连接，默认关闭。外部智能体通过标准输入输出协议启动本项目连接桥，桥只访问已核对安装目录的本机服务；平台密钥仍由深白片场保管。没有修改用户的全局 Codex、Claude 或其他客户端配置。

可用工具包括：列出普通画布、读取节点与修订号、查询模型和项目资产、批量创建/更新图片及视频节点、绑定资产和创建连线、撤销刚完成的编辑、请求生成、查看结果及继续查询已有任务。节点提示词可使用固定资产版本占位符，保存时编译为对应的 `@素材` 标记。

默认生成请求进入待确认列表。用户也可主动开启一次最长 30 分钟、最多 20 次生成请求的授权；这不是人民币预算，一次图片请求可能含多张图片。到期、次数用尽或关闭授权后，新请求重新等待确认。生成、查询和素材保存复用现有通道与资产系统。

外部编辑沿用现有实时更新。发生本地未保存草稿与外部修改冲突时，暂停保存并保留草稿，允许导出草稿后载入最新画布；不再自动重试覆盖新版本。服务端同时校验修订时间及内容版本。

## 使用方式

1. 启动“深白片场”，打开「设置 / API → 本地智能体（MCP）」。
2. 开启本地智能体访问，复制客户端配置，添加到支持 stdio MCP 的本地智能体中。保持深白片场程序运行；端口变化后重新复制配置。
3. 默认保留逐次确认。让智能体先读取画布、可用模型与项目资产，再创建或修改节点。
4. 需要执行生成时，在同一设置页查看待确认请求并批准；也可由用户主动开启本次授权。
5. 任务结果保存到项目配置的本地目录，并回写画布。网络或保存异常时查询原任务；提交不确定时先核对平台记录。

示例指令：

> 读取“测试”画布，使用我的人物资产图和场景图，创建两个视频节点，填写提示词并连接素材，先不要生成。

> 查看刚才的人物生图节点，申请生成，告诉我在哪里确认；得到任务编号后查询结果，不要重复提交。

本地智能体可使用其自身已安装的 Skill 来写提示词，再调用 MCP 写入画布；本版不替客户端安装技能或读取任意电脑文件。通过资产页导入素材后，用资产版本 ID 引用。

三组浏览器流程通过：MCP 设置与授权；外部更新冲突、草稿导出和最新画布载入；真实 stdio 进程连接本地控制接口，创建图片/视频节点及连线，经浏览器批准后执行模拟任务并实时回写结果节点。测试同时检查重放请求不重复生成、终态查询不反复修改画布。截图已人工检查，没有页面脚本错误。

全部开发验证使用独立工作区、测试素材和模拟生成。stdio 协议与应用操作是真实执行，图片/视频生成器用离线替代；测试视频只验证任务与结果字段，不作为真实视频播放或画质验收。未发起真实账号授权、收费 API、即梦生成或本地 GPU 任务。

协议依据：[MCP stdio 传输规范](https://modelcontextprotocol.io/specification/2025-06-18/basic/transports)、[MCP 工具规范](https://modelcontextprotocol.io/specification/2025-06-18/server/tools)。本版实现本地 stdio 子集，没有对外开放 HTTP MCP 服务或公网端口。

## 当前边界

- 仅普通画布；原版智能画布、任意节点类型、循环执行和完整无人值守制作流水线不在本次交付范围。
- MCP 本身不提供语言模型。对话与 Skill 由外部智能体负责，深白片场提供明确的画布和生成工具。
- 各生成通道仍受上一版已适配模型范围、账号权限与实际价格数据限制；未知价格不会当作零费用。
- 不自动安装/配置第三方智能体，不承诺所有客户端版本均已实测；真实客户端接入及收费生成需在用户环境验收。
- 已有的所有未完成产品需求保留于累计状态表，没有因版本号提高而视为完成。
