## 三、Agent 本版边界

- 单 Agent 工具循环，每轮最多 4 次模型调用，不是产品内多 Agent 团队。
- 对话产生模型费用；确认写入仅创建/更新节点，不自动批量生成媒体。
- 长期语义记忆、PDF/OCR、大剧本自动分批、后台长流程恢复与自动预算执行未实现。
- 技能限文本与引用规则；基础模板不能代表用户完整专业经验已经移植。
- 方案检查资产版本、项目归属和画布修订；画布变化会拒绝旧方案覆盖。
