# 0.11.0-studio.1 · 1020 反馈修复

- 日期：2026-10-20。
- 基于：0.10.2-studio.16；配套画廊 0.4.0 / schema 4。
- 类型：功能版本；在 `344996/deepwhite-studio-collab` 分批提交，原作者仓库不变。

## 本次新增与修复

1. **MCP**：设置页分别生成 Codex TOML 与 Claude/通用 JSON，增加连接检查、错误分类和诊断导出。Windows 便携配置使用固定入口，升级后自动找到当前版本。提供外接 Skill 和接入步骤。
2. **账户与模型**：登录/两步验证完成后，为当前用户创建或复用专用生成令牌、配置官方渠道并同步模型。网站会话和生成 Key 分开，Key 只在服务内存中；退出或切换账号立即失效。失败有状态及重试入口，自选 API 继续保留。
3. **节点与设置**：移除固定右侧属性面板，操作回到节点和选中工具条；媒体预览、提示词、模型和参数分层。两类画布共用工具位置与保存反馈，保留拖拽、连线和原生撤销。设置改为左侧分类。
4. **生成记录**：补媒体预览、类型/模型/状态/日期筛选、提示词复用及可读失败原因。没有实际账单时显示费用未知，不把估价当作真实扣费。
5. **意见反馈**：先保存本地草稿，可主动发送到配置的画廊；可附截图及最少诊断信息。画廊管理员查看、回复、调整状态并记录处理历史；画布能查询回复，断网重试不重复提交。
6. **内置助手移除**：正式启动入口不再加载内置 Agent、规划/应用路由和侧栏。共享模型目录、画布版本和编辑锁已提取为独立服务，MCP 与手动编辑继续共用。旧模块保留于源码供兼容测试和历史查阅，不作为运行入口。
7. 回归中修复文字/模型/参数编辑缺少撤销快照、设置异步刷新覆盖未保存输入、余额查询阻塞退出操作，以及 G2 提示词长度检查。

## 累计功能与未完成

完整继承清单见 [本版累计状态](0.11.0-studio.1-status.md)。微信继续暂缓。公共画廊尚未部署公网；站内直接付费生成、多媒体合集和完整运营系统未实现。任意节点和智能画布的 MCP 写操作、真实供应商/GPU 和长期性能仍需后续工作。

真实 API 站账户授权没有使用用户密码验证；使用 New API 官方契约的模拟服务验证自动连接。站点若关闭令牌接口或改变协议，会保留网站登录并显示连接未完成，可继续配置其他供应商。退出只清除本机授权，不删除网站令牌，用户可到 API 网站撤销。

## 使用与验证

- 设置 → 外接智能体：启用控制、检查连接、复制对应客户端配置；配置属于运行桥接的电脑。`127.0.0.1` 指桥接所在电脑，不是 API 网站。
- 设置 → API 服务：查看自动连接状态、选择其他渠道或重试模型同步。
- 设置 → 意见反馈：保存草稿、发送和查询回复；画廊管理员在“用户反馈”处理。
- 实际命令、测试数量、证据和本机运行方式见 [交付与验证](../../../docs/交付与验证-20261020.md)。
- 本轮不使用真实密码、付费生成或 GPU 任务；本机 Codex 联调不代表已远程修好另一台电脑。

## 数据兼容、备份与恢复

画布仍使用 schema 1，旧项目和任务回执保留。新增本地反馈草稿、授权绑定记录和固定 MCP 入口均位于用户数据目录。完整备份仍需同时包含 userdata 和外部项目媒体目录；授权绑定记录不是可离线恢复的生成 Key，重启后需重新登录。

画廊从 schema 3 追加反馈及处理事件表到 schema 4，迁移在事务内执行。启动升级前停写并备份数据库和媒体。回退旧画廊必须使用匹配的旧快照，不能把旧代码直接指向 schema 4；恢复旧快照前另存最新数据，避免丢失新增作品和反馈。

Windows 独立更新机制继续保留。此版本的本地构建与公共 Release 发布状态分开记录；源码提交不等于线上更新源已发布新版。
