# 0.6.0-agent.1 · 最小画布助手

本版累计已实现与未实现功能见[完整功能状态表](0.6.0-agent.1-status.md)。本文说明本次新增能力及操作方式。

本版本从资产基础提前实现用户确认的最小 Agent，未宣称此前规划的所有专业工具与执行端已完成。

## 两条使用路径

### 剧本 → 资产生图节点

进入任意普通画布，点击右上「画布助手」。选择已配置的对话模型、生图目标模型，以及「剧本资产拆解 · 基础版」或自己导入的成熟 Skill。上传 TXT、Markdown、DOCX 剧本，提出拆解范围和风格要求。可以多轮修改人物、场景、道具清单与提示词；生成方案后点击「确认写入画布」。生图节点仅填好草稿，不会自动生成图片。

### 片段与资产 → 视频节点

选择项目资产，或勾选「附带当前选中的画布节点」。选择视频目标模型与相关 Skill，说明片段内容和拍摄意图。需要理解图片外观时，勾选「让模型查看所选图片」，并使用支持图片输入和工具调用的对话模型。助手提出视频节点方案，预览列出每项素材与提示词的对应关系。确认后创建视频节点、参考素材节点和连接，自动填写 `@图片1` 等标记。

后台使用固定 version_id 绑定，画布可显示中文 @ 标记，正式提交时沿用既有模型适配转换。当前视频节点采用全能参考模式，不自动替用户猜测首尾帧模式。

## 对话与 Skill

- 会话绑定当前画布，关闭面板、刷新或重启后可继续。可以新建或切换会话。
- 附件可再次选用；之前对话携带的剧本在上下文预算内保留。长对话优先保留近期轮次，本版没有长期语义记忆。
- 单个附件最大 8 MB、30000 字符，超限明确拒绝，不悄悄截断剧本。文本需 UTF-8；暂不支持 PDF/OCR。
- 一次最多 3 个 Skill，支持 SKILL.md 与 references 文本；导入仍遵循现有 100 文件/500 KB 限制。
- 内置的两项是可编辑的基础模板，不冒充用户完整的专业 Skill。可在助手内导入自己的 Skill 文件夹。
- 每轮冻结技能文本与引用快照；不运行导入包里的 Python、Shell 或任意脚本。
- 单 Agent 最多 4 次模型调用、每次最多 8 个只读工具请求。对话会产生模型调用费用；只展示平台实际返回的 token 统计，不伪造人民币金额。
- 看图是显式选项，一轮最多 4 张，每张 8 MB、合计 16 MB；仅发送已选本地资产，图片携带版本标签。没有发送图片时，助手被要求不能声称看过外观。
- 需要 OpenAI 兼容的 chat/completions 与工具调用协议；目录启用不保证平台所有型号都支持工具，需要按所选供应商实际能力验证。

## 写入与恢复

方案在服务端校验模型、素材项目归属、文件存在、提示词和参考数量限制。不存在或歧义素材不能伪造 ID。

确认写入后，程序只改已展示的提示词和输入配置，保留目标节点已有生成媒体。更新节点会替换其输入连线，预览有明确说明。使用普通画布撤销可撤回整批节点与连线变更；未开始任何生图或视频任务。

方案产生后若节点或连接发生变化，写入会拒绝，用户应让助手重整方案。只移动视口不会改变方案版本。写入使用固定方案编号防止重复创建，服务在模型处理中重启也不自动重试计费请求。

存储在 `workspace/data/studio_agent/`；Skill 保持在 `workspace/data/studio_skills/`。会话包含用户剧本和提示词，属于私人项目数据。

## 验证与限制

- 新 Agent 后端 5 项检查覆盖工具循环、快照、重复请求、多轮附件记忆、DOCX、未知工具、重启中断、看图开关和失败修订。
- 节点方案 5 项检查覆盖无生成写入、幂等、固定素材映射、画布冲突、跨项目拒绝和保留已有输出。
- 原有生图、ComfyUI、MJ/计费与资产集成共 36 项回归检查通过。
- 浏览器真实走通上传→Skill→两轮对话→只读工具→方案预览→写入→撤销→视频映射→刷新历史；确认样式加载、发送按钮状态和方案重复应用行为。
- 测试使用独立临时工作区与模拟模型响应，无真实付费模型或 GPU 生成。
- 真实供应商工具协议兼容性、提示词创作质量和视觉理解准确性仍需使用实际模型验证；本版不承诺任意模型都能稳定输出节点方案。
