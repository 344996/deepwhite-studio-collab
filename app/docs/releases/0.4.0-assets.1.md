# 0.4.0-assets.1 · 资产基础首批实现

本版本落实设计中的资产身份、版本和画布引用。完整产品设计仍见 `../design-v0.3/README.md`，未把后续能力当作已实现。

## 使用

1. 首页进入项目后点击「项目资产」，或在画布右上点击同名按钮。
2. 导入图片、视频、音频，素材先作为候选保存。旧画布内可解析的本地媒体会在打开/保存时补充登记。
3. 点击「确认」，设置名称、类别，选择新建资产或成为已有资产的新版本。
4. 从画布内的资产面板点击「加入画布」，建立稳定的版本引用；不会复制或删除原节点。
5. 不再常用的正式版本可以归档。归档仍保留文件与引用；版本菜单可以查看同一资产的各版本。

API 与本地 ComfyUI 新任务在结果保存后登记候选，再报告完成。MJ 的成功媒体先保存本地；重复查询只读取任务和结果，不因本次资产功能重新提交生成。

## 存储与兼容

- 索引：`workspace/data/studio-assets/index.sqlite3`。
- 候选副本：`workspace/data/studio-assets/candidates/<项目编号>/`。
- 正式版本：`workspace/data/studio-assets/projects/<项目编号>/<资产编号>/`。
- 同内容在同一项目重复导入复用版本；不同内容的同名文件不会覆盖。
- 确认与资产归属变更保留 version_id 和 SHA-256。受管副本保护媒体，不因画布节点删除而清理。
- 旧节点原字段和原 URL 保留，新增 `studioAssetRefs`；旧画布不在启动时批量重写。
- 「检查文件」检查索引内的缺失文件，并恢复有确认记录且已完整落盘的中断操作。不是任意损坏数据库或所有丢失文件的恢复工具。

## 验证

所有测试使用临时工作区、模拟上游和测试素材，不产生付费调用。

- 资产模块测试：身份稳定、重复导入、同名文件、跨项目隔离、缺失文件与中断恢复。
- 集成测试：真实本地 HTTP 导入/确认/归档，画布保存与再加载，媒体 URL 可作为模型输入解析，MJ 下载复用。
- 浏览器：导入→确认→预览/版本→加入画布→保存与刷新→归档；面板关闭后不遮挡画布。
- 原有 API 生图、ComfyUI 与费用/MJ 协议回归测试。

已通过 45 项 Python 检查及上述浏览器完整流程。截图保存在 `test-output/assets-v0.4/`；真实付费模型未调用。

## 本批限制与下一步

- 当前使用软件自动管理的项目目录，尚未开放任意外部目录选择与双向同步。导入只复制文件，不更改外部原件。
- 不自动下载旧画布中任意远程 URL；本地缺失或无法解析的旧媒体保留原显示与原引用。
- 当前提供文件选择导入，未加入整目录递归导入。首次登记大素材需要额外磁盘空间。
- 本批不修改整体首页布局，不开启真实 Agent、微信扫码、自动更新或新增 RH/Comfy 工作流。下一批按 0.5 完成专业工具和执行端配置。
- 真实付费生成、所有外部媒体格式及生产规模压力仍需后续实测。

回退程序可使用开发前源码快照；原媒体和旧画布字段仍保留。不要将含私人配置的完整备份用于公开分发。
