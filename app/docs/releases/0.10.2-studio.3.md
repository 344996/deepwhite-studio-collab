## 撤销与任务

经典及智能画布不再把旧节点快照整批替换回来。恢复编辑时保留仍存在的节点对象、原生任务 attempt 身份、任务编号、固定输入及新结果；任务输出节点和连接独立保护。新的任务回执仍会使旧重做分支失效。

MiniMax 片段保留对象身份及撤销之后到达的结果，手动换片和片段参数仍可撤销/重做；只合并实际生成的新素材，不误保留同时手动导入的素材。删除片段再恢复时，暂停对应任务并拒绝旧查询写入新片段，其他片段不受影响；显式查询仍可使用原编号。输出修订只存于当前页面内存，不增加持久数据字段。修复智能画布查询返回字符串视频地址时未写入片段的问题。草稿导出与新副本不携带任务暂停标记，同项目恢复则保留服务端最新标记。

删除后撤销恢复使用新的节点对象，原任务编号保留，尚未完成的任务暂停或待核实；不复活旧异步回调，不自动提交或查询。保存刷新时，原生、即梦、增强通用任务及 RH 的自动恢复入口继续尊重暂停标记，缓存状态不把“待核实”显示回运行中；明确新任务在保存前清除对应旧标记。撤销不是远端取消。无归属或跨画布记录拒绝恢复，保留历史帧和当前数据。操作说明见[画布撤销与任务保护](../../../docs/画布撤销与任务保护.md)。

新提交保存失败、服务器明确拒绝或查询返回 404 后，自动恢复仍按该次请求编号核对，不能因为任务指针为空而接回同节点的旧任务。列表请求期间更换提交编号也会拒绝旧响应；用户明确重试可建立新的请求。

## 工具界面与性能

图片裁剪与预览、生成日志、内容库及经典画布助手统一使用共享深灰绿、暖金和米白配色，四主题跟随设置。保留裁剪像素、预设参数、Skill 多选和方案确认流程；日志的长错误允许换行阅读，经典日志补齐 Escape 关闭及上层弹窗保护。没有新增在线画廊。

定位大画布文本编辑卡顿的主要原因是每个生成器刷新引用时反复重建全页面图标。改为只初始化新图标和明确改名的图标，在一轮输入刷新结束时同步合并执行；已有 SVG 及其事件保留。没有有效 Skill 工作流连线时，不创建空装饰 SVG，也不读取整个画布尺寸强制布局；有关系时仍绘制真实工作流线。

## 性能实测及限制

环境：Windows、i5-14600KF、32 GiB、Edge 154 无界面浏览器，本地素材及 100/300 混合节点。基线与修复后按同一脚本、同样的长文本替换和分段真实输入测量；trace/CPU profile 保留在系统临时目录 `deepwhite-canvas-edit-performance-review`，最终标签 `final-with-fastpath`。

| 测量项目 | 修复前 | 本版实测 |
|---|---:|---:|
| 100 节点真实输入：引用刷新函数累计 | 215 ms | 3.6 ms |
| 300 节点真实输入：引用刷新函数累计 | 1498.6 ms | 28 ms |
| 300 节点真实输入：最长主线程任务 | 1732 ms | 74 ms |
| 300 节点整段替换：最长主线程任务 | 1628 ms | 247 ms |
| 300 节点整段替换/真实输入：阶段总时间 | 3017 / 2871 ms | 1389 / 1439 ms |

阶段总时间含浏览器驱动、保存等待和采样，不能解读为键盘延迟或每帧时长。100 节点两项最终采样均没有超过 50ms 的长任务；300 节点仍有样式与布局成本，原生地图尺寸读取、Tailwind 和模型全图监听仍需优化。草稿 capture 单次最高约 2.4ms，本次证据不支持把主要卡顿归因于保存序列化。

完整空间脚本仍测到 300 节点拖动最长任务 445ms、平移 235ms，切回画布约 4.18–4.28 秒。六次同页切换的 live DOM 23357、页面事件监听 24370 保持固定，window/document/board 监听为 68/33/15；短时计数稳定不能宣称长期零泄漏。空画布、普通 300 节点及移除最后有效 Skill 关系时无 workflow 几何读取；有关系时两条视觉连线端点正确，也不混入模型生成输入。
