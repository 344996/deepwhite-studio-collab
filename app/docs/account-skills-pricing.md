# 账号、技能库与估价（2026-09-23）

## 使用入口

- 首页和画布右上角新增「登录 / 账户」「Skill 库」。首页钱包显示登录账号的余额，可手动刷新。
- 登录复用 api.deepwhiteai.com 的用户名、密码和两步验证。注册、充值、找回密码在 API 网站完成。
- 密码不保存。上游登录 Cookie 只留在后台进程内存，本地浏览器只保存随机 HttpOnly 会话标识；12 小时或后台重启后重新登录。
- API 生成仍使用「设置 / API」中的密钥。账号登录不会自动创建密钥或覆盖原有密钥；账户余额与密钥限额是不同概念。
- 当前仍是本机单人画布，登录并不把已有项目改为云端项目，也不提供多人数据隔离。

## Skill 库

选择一个含 SKILL.md 的文件夹导入；支持 md、txt、json，单包最多 100 个文本文件、500 KB。
agent-skill.json 可用 instructionReferences 数组引用 references/ 下的说明文件。
不执行 Python、JavaScript、Shell 或其他脚本，也不会自动安装依赖。
可查看主指令和删除技能。在文本节点的「使用技能」选择后，生成请求会带技能编号，服务端读取主指令及声明的引用，合并到系统指令。任务记录保存实际使用的指令快照。
技能保存在当前运行目录 data/studio_skills 中。导入用户自己的技能，不附带复制 Fisher 的闭源技能。
这一版是手动选技能辅助文本生成，不含自动调度工具或自动创建节点的 Agent。

## 价格方法

参考本地 Fisher 的参数匹配机制，使用 DeepWhite 自己的 /api/pricing 数据，绝不套用 Fisher 售价。
优先匹配同模型、相同质量、比例、分辨率、时长、参考图数等历史记录。
只有同时具有质量和参考图数量的记录，才允许在其余参数相同情况下参考最近的参考图数量，并标记 approximate、提示费用可能变化。
缓存、历史区间、按 Token 结算及缺少价格证据仍明确显示。该方法不能凭空补齐网站未提供的模型价格。

## 验证与限制

离线账号接口测试覆盖两步验证、会话 Cookie、账户身份头、货币换算及退出；技能测试覆盖导入限制、路径安全、引用、指令加载和删除；估价测试覆盖准确匹配、相近参考图数、质量/比例不同拒绝匹配。
浏览器测试覆盖首页管理、登录入口、技能导入查看、文本节点选择技能。
本环境直接读取 API 网站公开接口返回 HTTP 403；真实登录、余额和实时价格仍需在可访问网站的环境验收。未执行付费生成。
