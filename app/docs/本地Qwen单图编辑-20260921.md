# 本地 Qwen 单图编辑

生图节点的平台选择「本地 ComfyUI」，模型选择「Qwen Image 2.1 · 单图编辑」。上传或连接一张图片，填写修改要求后生成。结果沿用画布原有生成结果节点，多张结果保留在同一结果节点。

当前连接 http://127.0.0.1:8188。默认选择本地节点后自动后台启动整合包，也可以点击「本地引擎设置」手动启动、修改目录、关闭自动启动或开启「打开 DeepWhite 服务时立即启动」。无需填写 API Key，不扣 API 额度。尚未实现选择端口、远程 ComfyUI 或 RunningHub。

执行模板来自 2026-09-21 已成功的单图编辑历史任务，保留输出 468 的依赖图，不包含示例人物图片、原始提示词或浏览器专用对比节点。模板为 workflows/qwen-single-edit.api.json，当前整合包目录 D:\deep\Comfyui。

输入：一张本地画布图片、编辑提示词；比例 1:1、16:9、9:16、4:3、3:4；步数 20/30/40（默认40）；总像素沿用原工作流约1MP。每次生成随机种子。多张生成顺序提交。

提示词优化默认关闭，直接传递用户要求；开启时使用原工作流的本地扩写节点及模型，未改写其模板。由于原扩写存在重复/视频化描述，建议先关闭使用。

适配前会检查节点类型、模型可选项和有效图片。收到任务编号后只查询历史，不重复提交；提交响应丢失时标记待核实，需先检查 ComfyUI 队列。结果复制到画布自己的输出目录。

验证：7项离线后端测试、17项原生成链路回归、浏览器模型选择/参数/模拟结果/重开测试通过。通过只读 object_info 核对当前引擎的模型和节点。未另行启动真实GPU生成，实际画质与执行耗时仍待用户试用。

## 本地引擎管理

画布右上角常驻 ComfyUI 控制栏，无需选中节点即可开启、关闭、打开设置；每3秒刷新未开启、启动中、运行中、失败或连接中断状态。外部启动的引擎会明确标注并禁用关闭。主动关闭成功后，同时保存关闭按需自动启动和随服务启动的偏好，刷新画布也不会再次拉起；用户仍可手动开启，或在设置恢复自动启动。

控制栏浏览器验收覆盖：空画布显示、开启、任务忙时拒绝关闭及提示、关闭后刷新不重启、再次手动开启、外部进程关闭按钮禁用。测试使用模拟引擎，未影响用户正在运行的 ComfyUI。

设置保存在运行数据目录 local-comfy-engine.json，启动日志位于同目录 local-comfy-engine.log。节点和基础设置均可打开设置窗口查看日志、失败重试。默认目录 D:\deep\Comfyui，使用其中 python/python.exe 启动 ComfyUI/main.py，绑定本机8188，禁止自动打开浏览器。沿用当前启动器中的显存管理、强制上转精度、fast设置；不更新插件或安装模型。

引擎就绪与模型加载是不同阶段。第一次生成仍需要加载模型。工作流节点及模型依赖在提交前再次检查，缺失时明确报错。

仅持有本次启动子进程句柄时允许关闭；用户自行启动或 DeepWhite 重启后重新连接的进程一律视为外部进程，不按端口或旧 PID 强制结束。引擎启动中、任务排队/运行中、无法确认队列时不关闭。后台服务退出时仅尝试关闭自己管理的空闲引擎；直接关闭浏览器标签页不等于退出后台服务。

自动启动并发、防止重复进程、端口占用、失败信息、关闭保护等8项离线测试通过。浏览器已验证自动准备触发、设置窗口和节点调用。测试不提交生图任务。

实际验收：从关闭状态后台启动当前整合包成功，system_stats/queue正常；Qwen模板需要的节点和模型均已通过object_info检查；重复启动请求复用原进程，未产生第二个引擎，任务队列为空。受限测试环境曾因Numba缓存目录拒绝写入而阻塞，正常本机权限下已通过。启动入口保留90秒慢启动堆栈诊断，服务就绪后自动取消诊断。
