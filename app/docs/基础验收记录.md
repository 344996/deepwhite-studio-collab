## 模型添加及画布选择修复（2026-09-17）

用户反馈获取模型后无法添加、画布无法选择。只读检查确认 DeepWhite 密钥已保存，但三类模型列表均为空。代码存在两个流程缺陷：底部保存不收集模型选择器勾选项；批量选择含待分类模型时整批添加被阻止。

- 列表按钮改为「添加并保存所选模型」，直接持久保存；底部「保存 API 设置」也收集勾选项。
- 已分类模型可以先保存，待分类项保留并在列表内提示；支持对当前筛选中已选模型批量归类。没有选择时明确提示。
- 已勾选模型属于未保存修改，关闭会提醒；设置加载完成前表单不可编辑，避免异步加载覆盖输入。
- `static/studio-models.js` 在两种正式画布中使用已配置的平台及保存的模型目录，默认平台排在首位；原项目未配置的默认平台不再挤占选择器。原画布核心源码不变。
- 扩展 `tests/check-settings.cjs` 验证混合分类批量添加、直接底部保存、实际操作三个节点的模型下拉框、保存刷新恢复；通过。
- `tests/check-settings.py` 共 5 组检查通过，包含中文模型名称分类建议；现有完整基础回归通过。
- 使用隔离目录及虚构密钥，外部请求和生成任务均为 0。真实项目的密钥、模型选择和节点不由测试修改。
