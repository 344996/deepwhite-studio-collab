# 第一阶段检查与剩余验收

本次检查使用隔离数据和模拟接口，未调用付费生成；没有改动用户画布数据。

## 本次修正与新增检查

- 移除 MJ 结果节点的一张一页模式，多张图片在同一个节点同时展示；大图查看使用上一张、下一张和张数提示，保留键盘方向键。单张图不显示翻页控件。不把一张 MJ 四宫格图片自动裁成四张。
- 模型选择框、模型列表、普通画布节点标题使用本地厂商图标。明确的系列匹配厂商，例如 Seedance/Seedream → 字节、Nano Banana/Gemini/Veo → Google、Claude → Anthropic、MJ → Midjourney。未确认的渠道别名使用 AI 占位，不能把转发平台当成模型原厂。图标来源和许可见 `static/vendor-icons/SOURCE.md` 和 `LICENSE`。
- 点击节点标题或拖动面后释放旧编辑框焦点；非编辑状态的 Delete/Backspace 删除选中节点，即使焦点在节点按钮上也生效。输入框、下拉框、弹窗和大图查看器中不触发画布删除。
- 新增模拟三张图同节点、大图翻页、计数、删除防护和撤销检查；逐类检查图片/视频生成、文本素材、图片素材、结果、语言和 MJ 工具节点删除。

## 第一阶段仍需补充的验收

1. **真实接口小样**：分别选择一个文本、图片、视频及 MJ 模型，检查请求、返回文件和最终账单。需要另行允许消耗额度，本次未执行。
2. **真实媒体文件**：大尺寸图片、真实视频/音轨播放、批量下载后的文件完整性和失败重试。当前浏览器主要检查入口，后端落盘用模拟媒体验证。
3. **复杂与长时间使用**：大画布数百节点、多任务并行、长时间挂起、真实网络断开/电脑休眠，以及多标签页同时编辑同一画布冲突。
4. **所有厂商型号**：动态目录中的每种型号、版本、区域渠道和参考素材限制，未逐一真实验收；未知厂商别名的图标归属需确认后补齐。
5. **其他设备与完整基础操作**：完整触屏操作、不同浏览器、复杂嵌套分组、组合快捷键与导入导出往返一致性，尚未做完整覆盖。不能用移动端预览布局通过代替正式画布可用性验收。

建议顺序：先确认本轮界面修正，再补真实媒体下载/播放和复杂画布检查，最后进行用户允许额度内的代表模型真实验收。
