# DeepWhite Studio 第一阶段

更新：2026-09-17。使用入口是工作台内的**普通画布**；`/preview` 是早期交互稿，不用于生成。

## 本阶段交付

完成文字、图片、视频的基础生成流程。继续使用干净无限画布的节点、连线、缩放、分组、复制、撤销、项目管理和素材库。音频生成和其他制作工具按后续阶段实施。

1. 右上角「设置 / API」保存 DeepWhite 地址和密钥，测试连接，同步模型。同步默认启用，用户可停用、移除、恢复；这些选择在下次同步时保留。
2. 双击空白处添加文本、图片、视频。模型菜单先选择系列，再选择具体版本；不需要选择 t2i、i2i 等接口名称。
3. 在节点中写提示词，可连接已有文本作为补充。文本支持生成、改写、自定义要求，原多轮聊天保留。
4. 上传、粘贴或拖入参考素材，也可以连线引用。素材可排序、替换、移除；视频可选择全能参考或明确首尾帧。
5. 参数只展示当前已核对的能力。Seedance 默认全能参考；没有素材时自动调用同系列文生视频，带参考素材时调用全能参考，选择首尾帧时调用图生视频。
6. 生成按钮旁显示估价及依据。缺少匹配的计费数据时显示未知，不用零元代替。生成完成后，若平台返回结算后的 `usage.amount/currency`，显示实际费用；否则显示待结算。
7. 图片、视频仍沿用原画布的结果节点，生成成功后保存本地文件。文本显示在文本节点内，可复制、下载或放入独立文本素材节点。
8. 左下角「生成记录」保存本次实际提示词、参考素材、参数、模型、任务编号和结果，可预览、下载、放入画布、复用设置。原素材库、「从作品导入」继续保留。
9. 双击节点标题可以重命名。画布自动保存，显式保存和自动保存按顺序执行，避免快速复制/删除/撤销时的保存冲突。
10. 左下角常驻「整理选中」「整理全部」。复用原画布按连线排列的功能，保留连线，支持撤销和保存；选中一个节点时，「整理选中」整理该节点相连的分支。

## 0.2.1 修正

- 全能图片 G2.5 低价版实际要求提示词为 **5–5000 个字符**，以用户提供的平台错误为准，修正文档旧下限。节点显示字数，过短或超长时禁止提交，后端再次校验。
- 平台返回具体错误时，生成记录和节点显示经过密钥隐藏处理的错误说明。原来仅记录 400、且提示词不足 5 个字符的对应低价模型旧任务显示补充诊断，不自动重新提交。
- Seedance 全能参考：先上传或连线添加素材，在提示词输入 `@` 选择图片、视频、音频，也可点击素材旁的引用标记。支持鼠标选择或上下方向键加回车。
- `@图片1` 等标记绑定具体素材，排序后仍保持关联；提交时转换成接口要求的 `@Image 1`、`@Video 1`、`@Audio 1`。保存和刷新保留关联；删除被引用的素材后，要求重新关联才能提交。
- 模拟验收覆盖上述字数限制、平台错误保留与密钥隐藏、混合素材编号、排序与刷新、缺失素材拦截，以及原生整理、撤销和保存。另通过基础画布和模型/MJ 交互回归；没有发起真实付费生成。

## 中断与重复提交

- 查询或下载暂时失败：显示「继续查询」，只查询原任务，不再次提交生成。
- 刷新后：通过保存的任务记录恢复状态与结果，已有结果不重复追加。
- 平台明确生成失败：保留原因，可由用户点击重新生成；新生成会产生新调用。
- 提交网络中断且无法确认平台是否接收：显示“提交结果待核实”，先核对平台任务和账单，不自动重复提交。
- 请求编号用于防止同一次提交重复执行。批量图片保留每个子任务编号，已成功的结果单独保留。

## 模型适配范围

本阶段提供常用模型的基础生成参数，不等于 API 网站的每一个专用工具都已开放。

- 文本：标准 Chat Completions 模型；视频提示词 IR 等特殊协议工具不冒充普通语言模型。
- 图片：全能图片 G2 / G2.5 / G2 低价、Nano Banana、Seedream、Qwen Image、Wan 2.7、Grok 文生图。型号支持哪些参考输入与参数，由能力表和实际接口共同校验。
- 视频：Seedance、Wan 3.0、Wan 2.7 Spicy、Hailuo H3、FLUX 3 常规生成，以及 DeepWhite V31 / GK / G-Omni 基础生成。复杂角色、扩展编辑等专用操作暂不混入基础流程。
- MJ：保留此前已经模拟验收的文生图和独立工具面板，采用各操作自己的参数与接口。
- 参数契约尚未核对的型号可以在模型管理中保留，但生成按钮会说明尚未开放；不会用错误协议尝试收费调用。
- 智能画布保留原交互及共用 API 适配；本次新增素材管理、统一动态参数与生成记录面板以普通画布为验收主界面。

接口依据：[DeepWhite 文档](https://api.deepwhiteai.com/docs/llms.txt)、授权 T8 对应调用实现；模型与计费数据取自 DeepWhite，Fisher 用于模型选择和估价交互参考。

## 验收方式与边界

**全部采用模拟生成，没有消耗真实生成额度。连接测试不等于模型真实生成已经验收。**

后端模拟上游验证真实请求路径和内容，包括素材上传、图片/视频异步查询、本地保存、多结果、文本、参数拒绝、费用数据、重复请求编号、提交超时、失败、重启恢复及平台地址绑定。

浏览器验证实际普通画布：提示词和连线文本、模型两级菜单、动态参数、素材上传/排序/替换/粘贴、估价、重命名、保存刷新、生成记录、下载入口、设置复用、文本改写与结果节点、中断查询。另回归原画布基础操作、API 设置和 MJ 操作。

测试使用临时数据目录和模拟密钥；浏览器测试服务禁止外部上游请求。真实用户画布、密钥和资产不作为测试数据。

后续真实验收建议先选一个文本模型、一个图片模型和一个视频模型做小样；是否消耗额度由用户另行决定。此项未在本次执行。

## 维护位置

- `studio_capabilities.py`：模型参数与参考素材能力。
- `studio_generation.py`：上传、协议适配、持久化任务、查询与本地保存。
- `static/studio-stage-one.js/.css`：普通画布第一阶段操作区与记录；两种画布的保存串行化。
- `workspace/data/studio_jobs`：生成记录与短时上传缓存，不写入 API Key。
- `tests/check-stage-one.py`、`tests/check-stage-one.cjs`：第一阶段模拟验收。
