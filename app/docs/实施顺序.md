# DeepWhite Studio 五阶段实施顺序

依据用户手写规划与后续修正整理，更新于 2026-09-17。每个阶段先把一个完整操作流程做稳，再增加下一项。

## 第一阶段：可正常使用的基础画布

目标：在普通无限画布中，连接 DeepWhite API，使用不同模型生成文字、图片、视频，并能保存、复用结果。

- 画布：创建、移动、缩放、连线、多选、分组、复制、删除、撤销重做、重命名、自动保存和重开。
- API：配置与连接测试、同步模型、自动分类、默认启用及手动删减、系列 → 版本两级选择。
- 文本：生成、改写、自定义提示词；保留原对话能力。
- 图片：同一图片节点支持文字生成或参考图生成，后台按素材匹配同系列接口。
- 视频：选择模型及其支持的参数，纯文字、全能参考、首尾帧按实际能力处理。
- 输入：节点内提示词加连接文本；素材上传、拖入、粘贴、排序、替换、移除、首尾帧角色。
- 输出：估价、任务状态、失败原因、手动重试、刷新恢复、记录、预览、下载、复用和素材管理。
- 先交付常用模型；专用模型契约逐项核对，未完成的不冒充可用接口。

当前实现与验证边界见 [第一阶段使用与验收](第一阶段使用与验收.md)。全部按用户要求做模拟验收，未消耗实际生成额度。

## 第二阶段：素材与制作辅助工具

用户明确列出的工具：**去字幕、3D 导演台、Blender 白模、截取关键帧、人设图**。

2026-09-19 先实施截取关键帧及图片处理中的标准人设图。具体使用和验证边界见 [关键帧与标准人设图](第二阶段-关键帧与标准人设图.md)。其余工具继续逐项确认。

建议补充到本阶段逐项评估：基本裁剪、尺寸调整、必要的图片修整、统一素材命名与归档。每项先定义输入、参数和输出，再决定是否单独做工具节点。

Blender 白模用于空间、构图和摄影机预演；3D 导演台用于调度与镜头设计。两者共享素材与场景结果，避免把所有操作堆进基础生图节点。

## 第三阶段：影视创作与工作流结合

用户修正的重点：**站位图、俯视图**。

建议逐步补齐：机位与空间关系、分镜组织、多视图/故事板、角色与场景资产引用、生成单元与视频镜头关联。此前并行开发的导演工具在本阶段明确数据交换与集成方式。

保留“素材 → 文本设计 → 图像/白模 → 视频”的连线复用。复杂工作流先做可保存模板，再考虑批量自动执行。

## 第四阶段：音频与音乐生成

通过 API 生成音频或音乐，支持预览、下载和作为视频参考使用。具体语音、音效、音乐模型的先后顺序再按需求确定。上传音频不等于完成音频生成。

## 第五阶段：调用开源模型

用户确认的两条路径：**本地调用、RunningHub（RH）调用**。

复用稳定的节点输入、任务状态和结果记录，在同一画布选择执行来源。分别增加本地环境与连接检查，或 RH 的凭据、工作流与参数映射；说明费用、运行位置和资源需求。

## 每个功能的完成标准

能输入 → 参数明确 → 请求正确 → 能看到状态 → 能得到并保存结果 → 能再次使用 → 出错可理解和恢复。测试不自动消耗生成额度。改变既定交互前按具体操作讨论，避免不断返工。
