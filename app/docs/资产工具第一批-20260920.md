# API 资产工具第一批

2026-09-20。ComfyUI、本地整合包、RH 工作流适配本轮暂缓；未清理、启动或修改 D 盘 ComfyUI 工作环境。此处记录实际交付，不将设计原型视为产品实现。

## 已接入正式普通画布

点击上传或生成的图片，在原图片处理工具栏进入：

- **标准人设图**：保留用户完整原始提示词、G2.5 高品质默认型号、4:3 单张灰底三宫格。界面明确三格内容，不再引入正侧背勾选。
- **人物处理**：换服装、换装备、换手持物。可填写要求，从画布选择参考或上传一张额外参考。默认提示词仅为首版基础规则，尚未作为用户独有经验验收。
- **场景视角**：改变视角、反向镜头。可补充布局参考及空间说明；界面说明不可见区域由模型补全。
- **涂改与修改**：在副本上画红色区域，原图不被覆盖；提交时传原图、位置标注图及可选替换参考。属于参考图引导编辑，不是原生 mask 协议，不能保证区域外完全不变。标注长边最多 1280，原始参考保持原图。
- **双图对比**：选择画布另一张图片，创建独立对比节点；滑动分界线，保存恢复、删除和撤销。两图等比适配，不做自动像素配准。本批未实现独立于画布缩放的同步细节缩放。

生成工具只列已有适配、已启用且支持参考图的 GPT / Nano Banana 型号，按系列与具体型号两级选择；参数来自现有能力接口，费用来自现有估价接口。估价未知不显示免费。参考图以 URL 固定到任务，避免将结果集合的全部图片错误作为人物参考。

已有任务引擎负责真正的生成、结果与刷新恢复。退出处理窗口不会提交；准备过程中关闭会中止后续提交，但已经上传的本地素材可能保留。手动点击生成仍会真实调用 API。

## 实现边界

新增 `static/studio-asset-presets.js` 保存工具 ID、分组、提示词和版本；`static/studio-asset-tools.js` 负责统一处理面板、参考素材、标注及对比。继续复用后端模型能力、估价、生成和保存接口，没有新建第二套模型调用系统。后期 Agent 可复用工具标识与参数结构。

比较节点沿用原输出节点承载图片，附加 studioCompare 元数据；不修改原画布序列化和删除撤销机制。它保存所选两个素材的快照，不会因来源节点后来更换图片而自动变化。
